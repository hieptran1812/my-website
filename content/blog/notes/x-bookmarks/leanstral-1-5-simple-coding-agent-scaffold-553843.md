## Summary

@eliebakouch calls the Mistral release nice, with a tech report, saying it replaces the complicated scaffold of earlier lean models with a simple coding agent and scales test-time compute with compaction every 200k. The quoted post announces Leanstral 1.5, claiming SOTA on FATE-H and FATE-X and 587/672 on PutnamBench at 10x cheaper budget.

## Background

Lean is a proof language, so these models prove math theorems. Compaction summarizes earlier context so the agent can keep working beyond its window.

## What I took away

- Simple agent loops can beat elaborate scaffolds.
- Compaction extends effective working time.
- Benchmark figures are Mistral's claims.
