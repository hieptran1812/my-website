## Summary

The author says they and a colleague used **Hy3** to settle a combinatorics problem open for about 50 years, calling it a Eureka moment for an open-weights model. The quoted post explains the problem: for a finite set of integers A, how much faster can the sumset A+A grow than the difference set A-A. A 1969 theorem bounded the exponent by 2, while the best constructions barely passed 1.1, and with the research agent Hyra and Hy3 they found a new result (text cut off).

## Background

The sumset A+A is all sums of two elements of A, and the difference set A-A is all differences. Comparing their sizes is a classic question in additive combinatorics. AI-assisted math discovery has mostly used closed models, so a result from an open-weights model is notable.

## What I took away

- Open-weights models are now being used for research-level math claims.
- Agent scaffolding plus a model can search for constructions humans missed.
- Wait for expert verification of AI-assisted math results.
