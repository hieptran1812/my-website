## Summary

The author wrote a new article on their experience using LLMs to write GPU kernels. They describe it as an embarrassingly verifiable process. The details are in the linked article.

## Background

GPU kernel work is easy to verify: you can check outputs against a reference implementation and measure speed directly. Tasks with fast, objective checks are well suited to LLM-assisted iteration because bad attempts are quickly caught.

## What I took away

- Pair LLM-generated kernels with automated correctness and speed tests.
- Tasks with cheap verification are good candidates for AI assistance.
