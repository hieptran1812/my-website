## Summary

Wafer announced v2 of its AI Performance Engineering resource list, which it calls the most comprehensive list for learning GPU and AI performance work. This version starts by following how a single inference request moves through the system. The link is in the thread.

## Background

AI performance engineering is the work of making models train and run faster and cheaper on hardware, through better kernels, memory use, batching and scheduling. Following one request from start to finish is a common teaching approach because it shows every layer the request touches.

## What I took away

- Use a curated list to plan a learning path instead of random reading.
- Trace a single request end to end to understand where latency comes from.
