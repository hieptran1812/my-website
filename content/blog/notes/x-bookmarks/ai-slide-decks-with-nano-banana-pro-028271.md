## Summary

The author says Nano Banana Pro can do essentially perfect text, so it can produce slides. Paired with Kling transitions, they call it a very cool new format for presentations and share a tutorial that does it all with an agent.

## Background

Nano Banana Pro is an image generation model, and Kling is a video generation model. Reliable text in images used to be a weakness of image models. Now slides can be generated as images and animated between.

## What I took away

- Accurate text rendering opens new uses like slide generation.
- Chaining image and video tools with an agent can automate presentations.
- Check image text for errors before presenting.
