## Summary

The author says CoinGecko API now supports **x402**, letting AI agents autonomously access crypto data. The quoted post explains that x402 is an open payment protocol from Coinbase that lets agents such as OpenClaw pay for price and market data using USDC. The author predicts machine-to-machine commerce is coming fast.

## Background

x402 builds on the HTTP 402 Payment Required status. A server asks for payment, and the client pays in a stablecoin like USDC and retries, with no account or API key. This lets software agents buy data per request without a human.

## What I took away

- x402 lets agents pay per request without sign-up flows.
- Set spending limits before giving an agent a wallet.
- Pay-per-call APIs could change how data services are priced.
