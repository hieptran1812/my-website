## Summary

Anthropic's engineering blog says it tasked Opus 4.6 with agent teams to build a C compiler, then mostly walked away. Two weeks later it worked on the Linux kernel. The post shares what this taught them about autonomous software development.

## Background

A C compiler is a large, strictly checked program, so it is a hard test. Agent teams run multiple agents in parallel with little human input.

## What I took away

- Long autonomous builds are becoming feasible.
- Strong tests and harness design make this work.
- Read the engineering blog for the lessons.
