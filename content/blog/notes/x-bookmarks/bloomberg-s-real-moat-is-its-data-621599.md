## Summary

The author says replicating Bloomberg is not about code or infrastructure but data. Over its lifetime Bloomberg reached out to exchanges, brokers, dealers, banks and data providers. The quoted post adds that you can vibe code the interface but not the $30M of data feeds behind it.

## Background

Vibe coding means building software quickly by prompting an AI. A software interface is easy to copy, but licensed data from many sources takes years and money to gather. This is why data access is often a stronger moat than software.

## What I took away

- Code is increasingly easy to copy; exclusive data is not.
- When judging a product, ask what part is hard to replicate.
- The $30M figure is from the quoted post.
