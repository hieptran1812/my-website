## Summary

The post says Google posted a demo of an agent that runs fully in the browser. It uses **Gemma 4 E2B**, WebGPU and Hugging Face Transformers.js. It can search history, summarize pages and manage tabs, with no servers and no data leaving the device.

## Background

WebGPU lets web pages use the computer's GPU, so a small model can run inside the browser. Tool calling means the model asks for actions, such as listing tabs, and the page runs them. Running locally helps privacy because data stays on the device.

## What I took away

- Small open models can now run useful agents inside a browser.
- Local agents keep browsing data private by design.
- Tool calling is what turns a small model into something that acts.
