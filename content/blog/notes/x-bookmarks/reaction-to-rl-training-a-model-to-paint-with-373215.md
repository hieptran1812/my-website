## Summary

The author says this may be their favourite AI thing they have ever seen. The quoted post says you can use RL to train a coding model to paint with JavaScript.

## Background

Painting with code means the model writes JavaScript that draws a picture, and reinforcement learning rewards outputs whose images score well. It shows RL can teach creative, visual skills through code, not just correct answers.

## What I took away

- RL can target creative tasks if the result can be scored.
- Code as an output format makes visual results editable and inspectable.
- Several other bookmarks discuss the same project, including an open TRL replication.
