## Summary

The Claude Code creator shares that Remote Control is rolling out to Pro users, with Team and Enterprise coming soon. The quoted post says it is rolling out to 10% and ramping, and gives steps: update to claude v2.1.58+, log out and in for fresh flags, then run /remote-control.

## Background

Remote control lets you steer a coding session on your machine from another device. Feature flags roll out gradually, so logging in again can refresh them.

## What I took away

- Update to v2.1.58 or later and try /remote-control.
- Re-login to refresh feature flags.
