## Summary

Unsloth created a tool-calling guide for local LLMs. It shows how to use open models like Qwen3-Coder-Next and GLM-4.7-Flash for function calling, with examples for story writing, Python execution, terminal tool calls and maths.

## Background

Tool calling lets a model output structured requests, such as running code, which a program executes and feeds back. Local models can do this too, keeping data on your machine.

## What I took away

- Local models can use tools.
- Start with simple tools like Python execution.
- Use the guide for working examples.
