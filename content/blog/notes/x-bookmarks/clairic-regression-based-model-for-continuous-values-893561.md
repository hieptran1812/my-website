## Summary

@mervenoyann reacts positively. The quoted post introduces Clairic, a system-one model based on regression instead of classification, unlike decision models such as Clef. This lets it estimate continuous values without listing choices upfront, and enables efficient extraction (the text is cut off).

## Background

Classification picks from a fixed set of labels, while regression predicts a number directly. Many tasks, like scoring or estimating quantities, fit regression better. System one refers to fast, direct responses without long reasoning.

## What I took away

- Use regression heads when the output is a number, not a category.
- Fast specialized models can complement large reasoning models.
