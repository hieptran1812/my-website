## Summary

The Excalidraw account thanks people at Anthropic for an official MCP server. You can try it in Claude by searching Connectors for Excalidraw, or use it in Claude Code and elsewhere. The quoted post says it went from a weekend project to an official server in under a week.

## Background

MCP (Model Context Protocol) lets AI assistants call external tools in a standard way. An MCP server for Excalidraw lets a model draw diagrams directly on a whiteboard canvas.

## What I took away

- Official MCP servers make diagram generation easy to add.
- Weekend projects can become official quickly in open source.
- Try it for architecture diagrams.
