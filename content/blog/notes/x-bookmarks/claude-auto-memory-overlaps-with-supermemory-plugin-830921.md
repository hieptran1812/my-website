## Summary

The author jokes that Claude validated, and killed, their product. The supermemory Claude Code plugin launched with the same claims: learning debugging patterns, preferred approaches and project context. The quoted post announces Claude's new auto-memory across sessions. They are glad big labs adopt memory.

## Background

Agent memory saves lessons from one session so later sessions start with context. When a platform adds a feature, startups building the same thing as add-ons face pressure.

## What I took away

- Platform features can absorb plugin ideas.
- Memory across sessions is becoming standard.
