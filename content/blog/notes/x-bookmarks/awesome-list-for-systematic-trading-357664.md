## Summary

Tom Doerr shares an awesome-systematic-trading GitHub repository. It collects resources for systematic trading and quantitative finance.

## Background

Systematic trading means following fixed, rule-based strategies instead of discretionary calls. An awesome list is a curated set of links to papers, tools and books.

## What I took away

- Use curated lists to find quant tools and papers quickly.
- This is a learning resource, not trading advice.
