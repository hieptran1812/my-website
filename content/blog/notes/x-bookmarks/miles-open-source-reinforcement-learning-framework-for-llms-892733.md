## Summary

Aravind Srinivas shares the GitHub repo **radixark/miles** with the line open-source RL-as-a-service. The link card describes Miles as an enterprise-facing reinforcement learning framework for LLMs.

## Background

Reinforcement learning for LLMs trains a model by having it generate answers, scoring them with a reward, and updating the model toward higher-scoring behavior. It needs coordination between generation, scoring and training, so dedicated frameworks are useful. RL-as-a-service means offering that pipeline as ready infrastructure.

## What I took away

- RL post-training is becoming packaged infrastructure rather than custom lab code.
- Miles is one repo to look at when comparing RL frameworks for LLMs.
- Check how a framework handles rollout generation and training together, since that is where most cost sits.
