## Summary

FFmpeg thanks Anthropic for sending patches. The quoted post introduces Project Glasswing, an urgent initiative to secure critical software, powered by Claude Mythos Preview, which it says finds vulnerabilities better than all but the most skilled humans.

## Background

Using a model to find software bugs helps maintainers if the fixes are real patches. FFmpeg is a widely used media library.

## What I took away

- AI bug finding yielded patches.
- Maintainers benefit.
- The skill claim is Anthropic's.
