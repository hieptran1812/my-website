## Summary

HeyGen says: write HTML, render video, built for agents. The link card describes HyperFrames as AI video you can actually edit, free and open source.

## Background

Video made from HTML is easy for an agent to write and edit because it is just code. The video can be rendered to a file. Editable output beats opaque generated video.

## What I took away

- Code-as-video suits agents.
- Editable output makes iteration easier.
- Check the GitHub repo.
