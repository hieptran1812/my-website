## Summary

The author says their agentic coding workflow has become meta and self-referential, with a flywheel spinning faster as their prompting is increasingly aimed at driving their own tools. They mention a weird prompt telling **Opus 4.5** to use something. The text is cut off.

## Background

In agentic coding, the model runs tools and edits code. Building tools that the agent itself uses, and prompting the agent to improve them, creates a feedback loop that compounds.

## What I took away

- Build tools that your coding agent can use and improve.
- Self-improving loops can compound gains.
