## Summary

The author says Anthropic's 'openclaw-killer' is complete and lists what shipped in four weeks, including texting Claude Code, many skills and MCP servers, Claude security, persistent memory and channels. The quoted post announces Claude Code channels, which let you control a session through MCPs, starting with Telegram and Discord, from your phone.

## Background

MCP (Model Context Protocol) is a standard way to connect tools to an AI model. Channels use it so you can message a running coding session from a chat app. The 'openclaw-killer' framing is the author's opinion.

## What I took away

- You can drive a coding agent from a messaging app.
- Remote control of agents raises permission and security questions.
- Competing products are converging on messaging-based agents.
