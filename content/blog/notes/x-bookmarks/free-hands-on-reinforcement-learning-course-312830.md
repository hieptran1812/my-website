## Summary

The author says RL is back and shares a course to get started. He explains RL is a key ingredient to post-train language models for long, complex and hard-for-humans tasks, especially with verifiable rewards such as maths or coding. The link is Paulescu/hands-on-rl, a free course from zero to RL.

## Background

Verifiable rewards mean the answer can be checked automatically, like running code against tests or checking a math result. RL uses that check as feedback to improve the model. This has become a main way to train reasoning models.

## What I took away

- Verifiable tasks such as code and math are where LLM RL works best.
- A free hands-on course is a practical way to learn it.
- Start with the course repo to try small experiments.
