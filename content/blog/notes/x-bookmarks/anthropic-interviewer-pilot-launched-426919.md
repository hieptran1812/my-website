## Summary

@AnthropicAI announces Anthropic Interviewer, a new tool to help understand people's perspectives on AI. It is available at claude.ai/interviewer for a week-long pilot.

## Background

The tool uses an AI to conduct interviews and gather views at scale, which can help a company learn how people feel about AI. The post does not give details about how results will be used.

## What I took away

- AI labs are using AI to run user research.
- Read the linked page for how the data will be used before taking part.
