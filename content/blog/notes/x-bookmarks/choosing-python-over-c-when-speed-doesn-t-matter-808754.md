## Summary

The author recalls forcing themselves to use C++ for tasks they could do 100x faster in Python, and says there was no point for that problem. They note C++ still has many important use cases. The quoted post jokes: I was a 10x engineer. Now I'm useless.

## Background

The 100x figure is about developer speed on that problem, as the author describes it. The point is that the best language depends on the task. The quoted joke reflects worry that AI coding tools change what skills are valued.

## What I took away

- Pick tools by the problem, not by prestige.
- Developer time often matters more than runtime speed.
- Skills that feel valuable can shift as tooling changes.
