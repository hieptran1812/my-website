## Summary

The author describes Sigma as a fully private AI browser running agents locally, with no cloud and no data leaving the device, open source. It runs Qwen, Gemma or Nemotron in the browser. The quoted post adds it uses the OpenClaw agent on free local models.

## Background

Local models run on your own machine, so data stays private and there is no per-token fee. The tradeoff is that small local models are usually less capable than cloud ones.

## What I took away

- Local agents suit privacy-sensitive tasks.
- Expect capability limits compared with large cloud models.
