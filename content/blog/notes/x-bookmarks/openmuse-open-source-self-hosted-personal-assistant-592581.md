## Summary

The author introduces **OpenMuse**, an open source, self-hostable personal assistant that works with any agent harness. It includes computer use for browser, terminal and files, connectors for personal apps, tracking for ideas and goals, and mobile and web support. The quoted post is Meta's announcement of **Muse**, its personal AI agent app.

## Background

Computer use means an agent can control a browser, terminal or files like a person would. Self-hostable means you run it on your own machines, keeping your data. Open clones of commercial agents often appear quickly after launches.

## What I took away

- Self-hosted agents give more control over personal data.
- Check what permissions an agent with computer use gets before running it.
- Harness-agnostic design makes it easier to swap models.
