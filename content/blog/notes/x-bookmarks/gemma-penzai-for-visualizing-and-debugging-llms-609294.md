## Summary

@gu_xiangming releases gemma_penzai, built during his time at @GoogleDeepMind. It can visualize and debug multimodal LLMs. Every layer is a building block that can be inserted, deleted or manipulated.

## Background

Penzai is a library for building and inspecting neural networks. Being able to edit layers makes experiments like ablations easier. This is useful for interpretability research.

## What I took away

- Editable layers make model surgery easy.
- Debug tools help understand model internals.
- See the GitHub repo to try it.
