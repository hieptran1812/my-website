## Summary

The post introduces Auto-Research Trading, a fully autonomous loop that lets an AI trading agent teach itself to trade. It is inspired by Karpathy's auto-research, which others use to evolve how agents work together. The code is open sourced on GitHub.

## Background

The auto-research pattern has an agent propose a change, test it against a metric, and keep it if it improves. In trading, the risk is overfitting to past data. No performance results are claimed in the post.

## What I took away

- The autoresearch loop is being applied far beyond ML.
- Backtests can overfit, so out-of-sample testing matters.
- This is educational context, not advice.
