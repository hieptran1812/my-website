## Summary

The author likes the new feature and shares an example where Opus on the Claude web interface explained MLA and DSA. The quoted post announces that Claude can now build interactive charts and diagrams directly in chat, available to everyone.

## Background

MLA and DSA are attention-related techniques used in some LLM architectures to cut memory or compute. Interactive diagrams help explain such mechanisms visually instead of with text alone.

## What I took away

- Ask the model for an interactive diagram when learning a hard concept.
- Visual explanations can speed up understanding of architecture ideas.
