## Summary

Tom Doerr shares flowsurface, a desktop charting tool for crypto markets, linking to its GitHub repository.

## Background

Flowsurface is a Rust-based project, as the repo name suggests, for viewing market data on the desktop. Open source charting tools can be an alternative to web platforms. This is a tool listing, not advice.

## What I took away

- Open source tools can replace paid charting apps.
- Check the repo for supported exchanges.
