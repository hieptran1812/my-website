## Summary

The author says perhaps soon wasm skills can run inside the LLM agent itself and finds wasm's applications fascinating. The quoted post says LLMs solve research-grade math but struggle with basic calculations, so they built a computer inside a transformer that runs programs for millions of steps in seconds, solving hard Sudokus with 100% accuracy.

## Background

WebAssembly (wasm) is a compact, portable code format. The quoted work claims a transformer can execute programs by itself instead of calling an outside tool. These are the authors' claims.

## What I took away

- Models that execute programs internally could remove tool-call overhead.
- Reliable arithmetic is still a weak spot for LLMs.
