## Summary

The author suggests asking Codex to create an image grid with six design variations labeled A to F, picking one and iterating to get A1 to A4 until you have what you want. Then they suggest pointing it to a blog on using RL to teach Qwen to paint with code so it tries to produce the design programmatically. The quoted post says you can RL a coding model to paint with JavaScript.

## Background

Generating several options side by side and refining the best is a fast way to explore design with AI. Rendering the chosen design with code makes it editable and reproducible, which links to research on teaching models to draw with code.

## What I took away

- Ask for multiple labeled variations at once to speed up design choices.
- Iterate in small steps from the best option rather than starting over.
- Turning a design into code makes it easier to edit later.
