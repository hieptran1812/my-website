## Summary

@Hesamation lists hands-on projects: fine-tune a small LLM, make a reasoning LLM, run RL on a game environment, build synthetic data, make a coding agent, build a deep research agent, and contribute to an agentic framework. They say these are worth 10 online courses and urge people to just code something.

## Background

Learning by building exposes real problems that courses skip. The projects cover the main stages of modern LLM work: tuning, RL, data generation and agents. The comparison to courses is the author's opinion.

## What I took away

- Pick one project from the list and build it end to end.
- Contributing to an open agent framework is a good way to learn in public.
