## Summary

The author says he does not get it. Claude Code is writing 100% of Claude code, yet Anthropic lists over 100 open developer positions.

## Background

Writing code is only part of engineering. Design, review, safety, infrastructure and research need people. Hiring may also cover other roles.

## What I took away

- Code generation does not equal engineering work.
- Roles shift toward review and design.
