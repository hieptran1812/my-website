## Summary

@riomadeit says Font Sniper is available now in Raycast. It extracts and downloads fonts from any website.

## Background

Raycast is a launcher app for macOS with extensions. Fonts used on a page can be identified from its code. Check font licenses before using downloaded fonts.

## What I took away

- Handy tool for designers and developers.
- Respect font licenses.
- Install from Raycast to try.
