## Summary

Elon Musk replies Cool. The quoted author says DeepSeek was called out for scraping 150k Claude messages, so they are releasing 155k of their own Claude Code messages with Opus 4.5. They also open source tooling to fetch, redact and publish data on HF.

## Background

Coding agent logs can be used as training data. Redaction removes secrets before sharing. The post frames this as personal data liberation.

## What I took away

- Redact secrets before sharing logs.
- Your agent logs can be useful data.
