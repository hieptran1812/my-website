## Summary

The author says someone built a stock trading backtesting system using large language models, written 100% in Python and available for free. No details on results are given in the text.

## Background

Backtesting runs a strategy on past data to see how it would have done. Using an LLM could mean generating or interpreting strategies. Backtests can mislead through overfitting or lookahead bias, so results need care.

## What I took away

- Check the code for lookahead bias and data leakage.
- LLM-made strategies still need out-of-sample testing.
- Educational tool, not advice.
