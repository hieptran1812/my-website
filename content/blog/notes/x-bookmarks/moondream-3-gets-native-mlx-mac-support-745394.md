## Summary

Moondream announces MLX native Mac support for Moondream 3. It runs on Mac, Linux and Windows for free with pip install moondream-station, with details on the blog.

## Background

MLX is Apple's machine learning framework for Apple silicon, so native support runs the model efficiently on Macs. Moondream is a vision-language model that can describe and answer questions about images.

## What I took away

- You can run Moondream 3 locally with pip install moondream-station.
- Native MLX support improves performance on Apple silicon.
