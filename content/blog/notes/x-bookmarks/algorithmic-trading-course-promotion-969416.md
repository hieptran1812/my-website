## Summary

The author says it is a myth that you need a Ph.D. for algorithmic trading and that you need 3.5 hours, Python and IBKR. They say that moving from a trading desk to coding full systems in Python they hit the common wall of having ideas but no clear way to run them live. The link promotes a cohort course.

## Background

IBKR is Interactive Brokers, a broker with an API for automated trading. Getting from backtest to live trading involves connecting to a broker and handling orders. This is a course advertisement, so the claims are the seller's.

## What I took away

- Running a strategy live is a separate skill from designing it.
- Treat course marketing claims with some skepticism.
- Test with paper trading before any real money.
