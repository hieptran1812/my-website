## Summary

Someone built a web-based System Design Simulator. You drag and drop components and simulate traffic, failures, latency and scaling in real time.

## Background

Interactive simulation helps build intuition for system design interviews and architecture decisions.

## What I took away

- Simulate failures to learn their effects.
- Use it to practice design interviews.
