## Summary

Ian Goodfellow calls this an amazing test of Gemini 3's multimodal reasoning. The task is to give the model only an image and have it write threejs code for a voxel art scene inspired by that image, as a single page. The post includes the prompt.

## Background

Multimodal reasoning means the model must understand an image and turn it into working code. Voxel art is made of small cubes, and threejs is a JavaScript library for 3D in the browser. The task checks perception, planning and code in one go.

## What I took away

- It is a simple, reusable test you can run on any vision-capable model.
- Success needs both image understanding and correct code.
- The praise is the author's opinion; try it yourself.
