## Summary

The author says Claude Code source code was leaked via a map file in the npm registry and links a zip download. This is an unverified claim in the post.

## Background

Source map files map minified code back to original source and can reveal it if published by mistake. Downloading unknown zip files is risky.

## What I took away

- Source maps can leak code if published.
- Avoid downloading unknown archives.
- Treat leak claims as unverified.
