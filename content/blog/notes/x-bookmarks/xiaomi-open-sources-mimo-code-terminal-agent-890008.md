## Summary

@Chinazhidx says Xiaomi open-sourced MiMoCode V0.1.0, powered by MiMo-V2.5, claiming Claude Sonnet 4.6-level performance, persistent memory, unlimited context and voice input. The quoted post says a model needs a solid harness and the project took 14 days and 5 people.

## Background

A harness is the code around a model that runs tools and manages context. The performance claim is the post's.

## What I took away

- Model and harness improve together.
- Test claimed parity yourself.
