## Summary

@DilumSanjaya vibe coded a ship selection UI for a space exploration game. The 3D assets came from Nano Banana and Midjourney, then Hunyuan3D. The UI was made with Nano Banana and Gemini Pro, with more details in the thread.

## Background

Vibe coding means describing what you want and letting an AI write most of the code. Here the author chains several tools: image generators for concepts, an image-to-3D model for assets, and an LLM for the interface. This shows how a solo developer can prototype game parts quickly.

## What I took away

- Chaining specialized AI tools can cover art, 3D and UI for a prototype.
- Image-to-3D models can turn concept art into usable assets.
- Check the thread for the exact workflow.
