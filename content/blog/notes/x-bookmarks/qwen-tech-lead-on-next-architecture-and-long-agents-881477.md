## Summary

@AlexGDimakis shares quotes from Junyang Lin, Qwen team tech lead: for the next-generation model they are probably using this architecture, and he imagines an agent running for 1-2 days and then having built your app, so memory and long context will be very important.

## Background

Long-running agents need to keep track of what they have done, which makes memory and long context central. The post does not name the architecture in its text, so check the linked source for it.

## What I took away

- Long-horizon agents depend on memory and long context.
- Open model labs are already planning around agents that work for days.
