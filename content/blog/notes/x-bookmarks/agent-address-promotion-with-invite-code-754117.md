## Summary

The post compares the 90s .com, the 2010s @ handle and now an agent address. It urges readers to claim theirs early and offers a free invite code.

## Background

An agent address would be an identity for AI agents to send and receive messages. The post is promotional and uses scarcity.

## What I took away

- Early-claim pitches are marketing.
- Check what the address actually does.
- Agent identity is an open problem.
