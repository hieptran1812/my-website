## Summary

The author says we are in the golden age of software, with talented engineers becoming agent maximalists. They set up the right environment and loop Claude Code and Codex over weeks, producing work like Pretext in the quote.

## Background

Ralphing refers to running an agent in a loop on a task for long periods. A good environment, with tests and goals, makes this work.

## What I took away

- Long agent loops need a good environment.
- Tests and goals guide agents.
- This is the author's enthusiasm, not proof.
