## Summary

@iScienceLuvr says they should have emphasized that the entire training pipeline was released open source, which no current state-of-the-art pathology foundation model does. It includes the public dataset, training code and weights. The quoted post introduces OpenMidnight, which claims state-of-the-art performance trained on 12k whole slide images with $1.6k of compute.

## Background

A pathology foundation model learns general features from tissue images that can be reused for many medical tasks. A truly open release lets others reproduce and improve it. The performance claim is from the authors.

## What I took away

- Fully open releases include data, code and weights.
- Small budgets can reach strong results in specialized domains, per the authors.
- Reproducibility is a selling point for scientific models.
