## Summary

The author was sceptical when Anthropic released a 30K word document and said Claude was trained to follow it. He says it kinda works and that red teaming found much better constitution following, a positive update for aligning models in nuanced ways. The quoted post says it works surprisingly well.

## Background

A constitution here is a long written description of values used in training. Red teaming means deliberately attacking the model to find failures. Good results suggest complex values can be trained in, which matters for safety.

## What I took away

- Detailed value documents may be trainable into models.
- Red teaming is how to test if values really hold.
- Results are reported by the researchers; read the source for detail.
