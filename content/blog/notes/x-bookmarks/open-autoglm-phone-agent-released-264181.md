## Summary

The author says they open sourced AutoGLM, a project that teaches AI to use smartphones like a human. After 32 months of development, they say it can go beyond chat and complete whole tasks inside mobile apps, such as ordering food. The code is on GitHub as Open-AutoGLM.

## Background

A phone agent looks at the screen and taps or types the way a person would. This lets it work with apps that have no API. It matters because many everyday tasks live only inside apps.

## What I took away

- Phone agents work through the screen, so they can use apps without APIs.
- Open-AutoGLM is available as an open model and framework to try.
- Check reliability before trusting an agent with orders or payments.
