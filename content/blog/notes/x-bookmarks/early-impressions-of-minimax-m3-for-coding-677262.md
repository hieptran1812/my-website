## Summary

The author has tested M3 for a morning and says the subjective feel is close to Opus 4.7, pending more testing. They use M3 to write code and Opus 4.8 plus GPT5.5 for adversarial code review, and completed one PR. The quoted post lists benchmark scores such as 59.0% SWE-Bench Pro and 1M context.

## Background

Adversarial review uses a second model to criticize the first one's work. SWE-Bench Pro tests real software tasks.

## What I took away

- Mixing a cheap writer with strong reviewers is a workable pattern.
- Early impressions are subjective.
