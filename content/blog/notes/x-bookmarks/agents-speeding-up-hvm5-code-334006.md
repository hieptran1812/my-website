## Summary

@teodorio finds Monte Carlo simulation coding a cool concept. The quote says 32 GPT 5.5 agents on separate machines each got HVM5's unoptimized file and were asked for a 10x speedup; after 4 rounds all reached about 2x.

## Background

Running many agents in parallel samples many solutions, like Monte Carlo. Results are the author's report.

## What I took away

- Parallel agents give many attempts.
- Gains were about 2x, not 10x.
