## Summary

Telegraph says autonomous agents do not care about dashboards and only pull ranked intelligence. It invites builders to connect an API, climb rankings and be routed into machine queries, with its Season I Hackathon ending Aug 31. The link card says Stop building UIs. Build endpoints.

## Background

The pitch is that agents consume data through APIs, not visual interfaces, so builders should offer endpoints. This is a promotional post for a hackathon and platform.

## What I took away

- Designing for agents means clean, reliable APIs rather than UIs.
- Treat platform promotions skeptically and read the terms.
- The deadline in the post has likely passed.
