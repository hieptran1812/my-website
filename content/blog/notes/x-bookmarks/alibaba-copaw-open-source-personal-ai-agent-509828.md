## Summary

The author says Alibaba released an open source framework like OpenClaw plus Claude Cowork, self-hosted with persistent memory and skills. The quoted post announces CoPaw is now open source after overhauling the engine, with model freedom and local-first support.

## Background

A self-hosted agent runs on your own machine and keeps data local. Persistent memory and skills let it retain context and reusable abilities.

## What I took away

- Self-hosted agents are growing in number.
- Compare with OpenClaw before choosing.
