## Summary

Mihail Eric announces the newest edition of his Stanford course **The Modern Software Developer**, which took nine months to prepare. He says that coding agents improved in a step function after the release of Claude Opus 4.5 last November. The post is cut off before the course details.

## Background

Coding agents are AI systems that read a codebase, write and run code, and fix errors in a loop. As they get better, the skills a developer needs shift toward specifying tasks, reviewing output and designing systems. Courses like this try to teach that new workflow.

## What I took away

- Developer education is being rebuilt around working with coding agents.
- Model releases can change practical workflows quickly, so course material needs frequent updates.
- Open the link for the syllabus and any public materials.
