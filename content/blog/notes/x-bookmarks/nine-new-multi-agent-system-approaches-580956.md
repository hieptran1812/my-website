## Summary

The post lists 9 new approaches to multi-agent systems: RecursiveMAS, OneManCompany (OMC), OrgAgent, CORAL, LLMA-Mem, Agentic Federated Learning, CASCADE, GRASP and Reinforced Agent. It says these express interesting ideas and links to learn more.

## Background

Multi-agent systems have several LLM agents with roles who coordinate on a task. Research explores structures like organizations, memory sharing and recursion. The post is a pointer list.

## What I took away

- Use the list as a reading queue for agent coordination ideas.
- Compare how each handles memory and roles.
