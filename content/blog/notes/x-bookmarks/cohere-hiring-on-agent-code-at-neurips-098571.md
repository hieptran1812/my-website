## Summary

The author says they will present work at NeurIPS for Cohere and Cohere Labs. They are looking for people to join their team and are happy to chat about agentic code, synthetic data and RL. The card links a Member of Technical Staff, Agent Code job about code LLMs and agent systems that work with minimal human oversight.

## Background

NeurIPS is a major machine learning conference where companies recruit. Agentic code means models that write and run code as part of multi-step tasks. Synthetic data is training data produced by models.

## What I took away

- Conferences are a good place to meet hiring teams.
- Agent code, synthetic data and RL are active hiring areas.
