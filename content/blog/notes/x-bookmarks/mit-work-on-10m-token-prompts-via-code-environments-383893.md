## Summary

@MatthewBerman says MIT researchers destroyed context window limits. He claims 10M+ token prompts are possible by moving context out of the model and into code environments. He links a full breakdown.

## Background

A context window is how much text a model can read at once. Instead of enlarging it, the idea is to keep the text in a code environment where the model can search and process it. The destroyed limits wording is the author's claim.

## What I took away

- Context can live outside the model and be queried.
- Code environments let models work on huge inputs.
- Read the paper for the real results.
