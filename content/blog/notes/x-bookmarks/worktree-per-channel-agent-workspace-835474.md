## Summary

The author says each channel is a new worktree and you can drag and drop your agents. They call it probably the most fun way to work with agents. The demo is in the media.

## Background

A git worktree is a separate checkout of a repo, so agents can work on different branches without interfering with each other. Mapping them to chat channels makes parallel agent work easy to manage.

## What I took away

- Use one worktree per agent to avoid conflicts.
- Good interfaces make multi-agent work easier to manage.
