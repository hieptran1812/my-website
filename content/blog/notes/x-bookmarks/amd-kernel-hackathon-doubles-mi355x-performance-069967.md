## Summary

SemiAnalysis praises GPU MODE for running a **$1.1 million AMD kernel hackathon**. It says the GPUMODE Readonflow team's kernels improved end-to-end MI355X performance by over 2x. The thread goes on to explain the optimizations.

## Background

A kernel is a small program that runs on the GPU to do one operation, like matrix multiply or attention. MI355X is an AMD data center GPU. AMD's software stack has lagged NVIDIA's, so better kernels can unlock much more of the hardware's real performance.

## What I took away

- Software, not just hardware, often decides real GPU performance.
- Community hackathons with prizes can speed up ecosystem kernels.
- Read the thread for the specific optimization techniques.
