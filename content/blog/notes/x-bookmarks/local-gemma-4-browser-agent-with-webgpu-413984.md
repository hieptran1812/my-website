## Summary

The post shows a completely local agent in the browser, powered by Gemma 4 E2B and WebGPU. It uses native tool calling to search browsing history, read and summarize pages and manage tabs, all local with no servers.

## Background

WebGPU lets web pages use the GPU for compute. A small model like E2B can run on-device. Tool calling lets the model act on browser features. It is a demo, so capability limits apply.

## What I took away

- Small models can run useful agents in the browser.
- Local execution avoids server cost and data sharing.
