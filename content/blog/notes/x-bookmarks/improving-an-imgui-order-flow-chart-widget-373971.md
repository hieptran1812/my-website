## Summary

The author improved their ImGui chart widget. They added a new footprint cluster type for bid-ask and delta, better profile spacing, session, visible and fixed-range volume profiles, a tooltip for the orderbook heatmap, and a fullscreen mode.

## Background

ImGui is a library for building fast immediate-mode user interfaces. Footprint charts show traded volume at each price inside each candle. Custom tools like this are common among traders who build their own software.

## What I took away

- ImGui suits fast, data-heavy trading UIs.
- Footprint and volume profile views show order flow detail.
- Small usability features like tooltips and fullscreen matter.
