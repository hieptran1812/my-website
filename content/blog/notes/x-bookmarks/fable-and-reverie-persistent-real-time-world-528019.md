## Summary

@sunfanyun says Fable + Reverie gives infinitely persistent, real-time interactive output. The quoted post says Fable 5 made it with no external assets using Three.js and links a demo.

## Background

Three.js is a JavaScript library for 3D graphics in the browser. Persistent means the world keeps its state as you move. Details are in the linked demo.

## What I took away

- Try the demo to judge quality.
- Coding models can generate whole interactive scenes.
