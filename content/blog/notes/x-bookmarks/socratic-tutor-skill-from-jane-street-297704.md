## Summary

The author points to a Socratic tutor skill from Neon and Jane Street, hosted on GitHub. They describe it as a method for learning that does not feel like chatting with low-quality AI output.

## Background

A Socratic tutor asks guiding questions instead of handing over answers. An agent skill is a packaged set of instructions that tells a coding agent how to behave. Using one can push an LLM toward helping you think rather than just giving results.

## What I took away

- Ask an LLM to question you instead of answering for you when learning.
- Agent skills can change the style of help you get.
- Check the repository to see how the tutor prompt is written.
