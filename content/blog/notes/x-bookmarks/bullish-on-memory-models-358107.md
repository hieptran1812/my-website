## Summary

@jramapuram says memory can mean in-context learning, generative replay with distillation, or writing to memory in the architecture like the Kanerva Machine. The quoted podcast covers what the next training paradigm looks like, including grindability, RLVR generalization and dreaming.

## Background

Memory models store information beyond one context window. Getting learning back into the weights is an open research question.

## What I took away

- Memory has several distinct meanings.
- Continual learning is a major open problem.
