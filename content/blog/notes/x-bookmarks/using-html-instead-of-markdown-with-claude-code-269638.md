## Summary

The author claims HTML is the new markdown. They have stopped writing markdown files for almost everything and switched to using Claude Code to generate HTML, and say they will explain why.

## Background

Markdown is plain text with light formatting. HTML can include layout, color, charts and interactivity, which models can write easily. The tradeoff is that HTML is harder to edit by hand and diff.

## What I took away

- Agents can produce richer documents than markdown at little cost.
- Weigh richness against how easily you can review and edit the file.
