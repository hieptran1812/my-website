## Summary

Pekka Enberg says the post is not a blog post but a book. He quotes Sebastian Aaltonen announcing his No Graphics API blog post and asking for reposts.

## Background

A graphics API such as Vulkan or DirectX is the interface programs use to talk to the GPU. The title suggests a proposal for a much simpler or different way to program GPUs, but the post does not give details. It is a long read for people interested in GPU design.

## What I took away

- Long-form posts can be worth setting aside time for.
- Open the blog to see the argument for simplifying GPU APIs.
