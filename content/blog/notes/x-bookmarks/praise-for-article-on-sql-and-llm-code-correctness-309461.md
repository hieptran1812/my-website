## Summary

The author calls it perhaps the most well researched technical article on X, saying he learned more about SQL databases from it than in his whole career. He says the argument about plausible versus correct code from LLMs is well articulated.

## Background

LLM code can look right and still be wrong. Databases are a good test because subtle semantics and performance issues are easy to miss.

## What I took away

- Plausible code is not the same as correct code.
- Test LLM output rigorously, especially for databases.
