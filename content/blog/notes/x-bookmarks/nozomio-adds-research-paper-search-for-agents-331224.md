## Summary

Arlan announces research papers as a technical source for agents. You can index any paper and search it through the Nozomio API or MCP server. It supports arXiv, PDFs and raw IDs, and is globally deduped so already indexed papers are instant.

## Background

MCP is a standard way to connect tools and data to AI agents. Giving coding agents access to papers helps them implement methods from the source. Dedup means a paper indexed once is shared for everyone.

## What I took away

- Agents can use papers as context for implementing methods.
- MCP servers make such tools easy to plug in.
