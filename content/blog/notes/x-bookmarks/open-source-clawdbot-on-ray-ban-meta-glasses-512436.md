## Summary

The author is enthusiastic about Clawdbot running on Ray-Ban Meta glasses and notes it is open source. The quoted post says it is open source now and gives the VisionClaw GitHub link, so the bot can see through the glasses.

## Background

Smart glasses have cameras and microphones. Connecting them to an agent lets the agent answer about what the wearer sees. Privacy matters because the camera captures people nearby.

## What I took away

- Wearables give agents live visual input.
- Consider privacy when streaming a camera to a model.
- Open source lets you inspect how it works.
