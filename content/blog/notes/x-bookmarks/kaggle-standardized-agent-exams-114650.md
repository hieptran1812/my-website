## Summary

Omar Sanseviero introduces Kaggle Standardized Agent Exams. Agents register to an exam, solve it and join a leaderboard.

## Background

Standardized exams give a shared way to compare agents. Leaderboards motivate improvement but can be gamed.

## What I took away

- Shared exams make agents comparable.
- Check what the tasks measure.
- Leaderboards can encourage overfitting.
