## Summary

Pika announces a beta video chat skill for any agent, powered by its new real-time model PikaStream1.0. It says the skill keeps memory and personality and works in real time.

## Background

Real-time video generation lets an agent appear with a face and voice. Pika argues conversations go better that way. The post is a product announcement.

## What I took away

- Faces and voices are a new agent interface.
- Memory across calls matters for personality.
- Beta claims need hands-on testing.
