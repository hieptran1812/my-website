## Summary

Dune announces Dune MCP, which plugs Dune into Claude, ChatGPT, Cursor and more. From a single prompt you can search tables, write queries, build charts and check usage.

## Background

MCP is a protocol that lets AI assistants call external tools. Dune is a blockchain analytics platform. This lets natural language drive data queries.

## What I took away

- MCP makes data platforms accessible to agents.
- Verify AI-written queries before trusting results.
