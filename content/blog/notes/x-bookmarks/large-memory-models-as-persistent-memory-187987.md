## Summary

The author says a Large Memory Model (LMM) is a new architecture. Unlike an LLM, which compresses text into weights, an LMM captures what you saw, who you talked to and where you were, and surfaces it at the right time. The quoted Engramme post says persistent memory is AI's Achilles heel and opens a beta.

## Background

LLMs forget between sessions unless given context. A memory system stores and retrieves personal context. Whether this is a new architecture is the company's claim.

## What I took away

- Persistent memory is a real gap in current AI.
- Be cautious of new architecture claims without technical detail.
