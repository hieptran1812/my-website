## Summary

The post explains token bucket, where tokens refill at a fixed rate and each request uses one, and requests are throttled when empty. Fixed window counter divides time into windows. The text cuts off before the other three.

## Background

Rate limiting protects services from overload. Algorithms differ in burst handling and memory use.

## What I took away

- Know token bucket and fixed window.
- Pick based on burst tolerance.
