## Summary

The author says you should use Claude Code to run your whole work day and shares a talk with @davekilleen, field CPO at Pendo. Timestamps cover a command that plans his day, his CLAUDE.md setup, skills vs MCP vs hooks, and why he left Cursor for the terminal.

## Background

CLAUDE.md is a file of standing instructions Claude Code reads. Skills, MCP servers and hooks are different ways to extend an agent: reusable instructions, external tool connections, and automatic triggers.

## What I took away

- A single planning command can anchor a daily workflow.
- Keep standing context in CLAUDE.md.
- Learn the differences between skills, MCP and hooks.
