## Summary

He says the author must be followed. The quoted post says Code Mode is all you need and is excited about the direction for MCP, linking a Cloudflare blog.

## Background

MCP connects models to tools. Code Mode has the model write code to call tools instead of calling each as a separate function.

## What I took away

- Letting models write code to call tools can cut context cost.
- Read the Cloudflare blog.
