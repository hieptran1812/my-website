## Summary

@yong_zhengxin draws two takeaways from Anthropic's blog: an agent-computer interface research area will rise, and domain-specific harnesses keep moats because domains differ. The blog says bio databases are like cities built before cars.

## Background

Tools built for humans are awkward for agents. Redesigning interfaces for agents helps them.

## What I took away

- Design tools for agents.
- Domain harnesses matter.
