## Summary

@jefftangx predicts that Anthropic will acquire Linear and says coding is solved after Opus 4.5. The author argues that developers building CLIs and IDEs are working at the wrong level of abstraction, and lists current agent bottlenecks such as PR reviews. The quoted post predicts that either OpenAI or Anthropic will acquire @linear.

## Background

Linear is a project and issue tracking tool. The argument is that if coding agents can write code, the hard parts shift to reviewing changes and managing tasks, which is where tools like issue trackers sit. This is a prediction and opinion, not a fact.

## What I took away

- The bottleneck for coding agents may move from writing code to reviewing and task management.
- Treat acquisition predictions and the claim that coding is solved as opinion.
