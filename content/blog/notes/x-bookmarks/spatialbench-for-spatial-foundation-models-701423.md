## Summary

The post asks if your spatial foundation model is an all-round player and presents **SpatialBench**: 19 source datasets, 540+ scenes, 40+ model variants and 6 reconstruction paradigms. The quote calls it the first cross-paradigm benchmark for spatial foundation models. Project and code links are given.

## Background

Spatial foundation models reconstruct 3D structure from images or video. Different methods are usually tested on different data, so a shared benchmark makes comparison fair.

## What I took away

- Shared benchmarks make 3D model comparisons fair.
- All-round performance can differ from a model's headline strength.
- Use the code to test your own model.
