## Summary

The author calls the Kimi Code CLI a milestone for Moonshot, because they will be coherently optimizing their models for using this harness. He claims they are consistently 4-6 months ahead of DeepSeek on agentic work. The quote just links the Kimi Code CLI repo.

## Background

A harness is the agent scaffolding around a model: tools, prompts and loops. Training a model for its own harness can improve results. The lead over DeepSeek is the author's opinion.

## What I took away

- Co-designing model and harness is a clear trend.
- Treat lead-time claims as opinion.
- Look at the Kimi Code CLI repo to see the harness design.
