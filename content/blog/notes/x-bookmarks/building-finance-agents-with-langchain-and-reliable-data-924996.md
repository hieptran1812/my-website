## Summary

The author has built finance agents for 3 years and says two problems keep showing up: how to build the agent and how to give it reliable data. They say LangChain is the best framework for the first and that they are building findatasets for the second.

## Background

An agent is an LLM that uses tools in a loop. Frameworks like LangChain provide the building blocks. Data quality limits an agent: wrong inputs produce wrong analysis. The author is promoting their own product.

## What I took away

- Agent quality depends on the data it can access.
- Separate framework choice from data sourcing.
- Note the author's interest in the data product.
