## Summary

Sherlock says it shipped Sherlock AI V2.1, bringing the model closer to how experienced human auditors think and work. The release adds a scope-aware research architecture, deeper security methodologies and improved prompt design. The post is cut off after that.

## Background

Smart contract auditing means reviewing blockchain code for security holes. AI auditors try to automate part of this by reading code and following known attack patterns. Scope-aware means the tool knows which parts of a codebase are in scope. The claims come from the vendor.

## What I took away

- AI tools are being built to assist security audits.
- Treat vendor claims about matching human auditors with caution.
