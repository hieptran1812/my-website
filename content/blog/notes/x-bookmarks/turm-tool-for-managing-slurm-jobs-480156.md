## Summary

The author says turm looks incredibly useful for managing Slurm jobs and links its GitHub repository.

## Background

Slurm is a job scheduler used on many GPU and HPC clusters. Users submit jobs to a queue and check on them from the command line. A terminal UI can make monitoring and canceling jobs faster.

## What I took away

- A terminal UI can make cluster queues easier to watch.
- Try turm if you run jobs on Slurm clusters.
