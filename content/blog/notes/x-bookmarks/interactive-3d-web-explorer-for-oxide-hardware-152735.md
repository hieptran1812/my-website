## Summary

The author built a web 3D explorer for Oxide Computer using three.js and r3f. It has many small interactions and details, and guided tours. The post links to explorer.oxide.computer.

## Background

r3f is React Three Fiber, a React wrapper for three.js. Oxide builds rack-scale server hardware. Interactive explorers are a good way to show complex hardware to non-experts.

## What I took away

- React Three Fiber is a practical way to build 3D product explainers.
- Guided tours help make complex products easier to grasp.
