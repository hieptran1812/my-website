## Summary

Replying to a post that says Hugging Face should become a vibe coding platform, the author says they already have one. They call **DeepSite** the most underrated thing on Hugging Face, powered by open models, with great results.

## Background

Vibe coding means building software by describing it in natural language and letting a model write the code. DeepSite is a Hugging Face app for generating sites this way using open models.

## What I took away

- Open-model coding tools are available on Hugging Face.
- Try DeepSite for quick prototypes.
