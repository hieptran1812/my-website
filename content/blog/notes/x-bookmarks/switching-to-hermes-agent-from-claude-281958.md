## Summary

The author says he fully moved to Hermes Agent from NousResearch, using Codex 5.3 with OAuth through OpenAI to avoid burning credits, and calling Claude through OpenRouter sub agents for writing. The quoted post claims Claude is absurdly nerfed right now. That is an opinion.

## Background

Agent harnesses let you swap models behind one interface. Using subscription OAuth can be cheaper than API credits, and sub agents route tasks to the best model.

## What I took away

- A model-agnostic harness lets you route tasks to different models.
- Claims that a model got worse are subjective; measure yourself.
