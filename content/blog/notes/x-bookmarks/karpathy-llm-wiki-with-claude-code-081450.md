## Summary

The author used Karpathy's LLM Wiki to turn Claude Code into a self-evolving system. They fed it frontend and CRM sources and it built an updating dashboard with Shadcn that keeps linking things. The quoted post describes using LLMs to build personal knowledge bases.

## Background

The idea is to let an LLM maintain a wiki of notes on topics instead of mainly writing code. Linking the notes gives better context.

## What I took away

- LLMs can maintain knowledge bases.
- Link notes for context.
- Try it on your own sources.
