## Summary

The post says Stanford researchers gave an 8B model 108 times fewer document tokens and it became more accurate at verifying facts. Memorilla is an open-source memory system that lets LLMs use large document collections through just 16 learned memory tokens. The text is truncated.

## Background

Instead of feeding all documents into context, the system compresses them into a few learned tokens. This saves context cost. The figures are from the post.

## What I took away

- Compressing context can save cost.
- Learned memory tokens replace raw text.
- Check claims in the paper.
