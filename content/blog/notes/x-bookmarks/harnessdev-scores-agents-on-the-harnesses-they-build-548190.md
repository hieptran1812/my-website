## Summary

Elvis Saravia recommends a ByteDance Seed paper on self-evolving agent harnesses. He says the method, **HarnessDev**, stops scoring a model on the tasks it completes and instead scores it on the harness it builds. The post is cut off while describing how the agent starts.

## Background

A harness is the code around a model that gives it tools, memory, prompts and control flow, turning a raw model into an agent. A self-evolving harness is one the agent edits and improves itself. Scoring the harness rewards building reusable machinery instead of solving one task at a time.

## What I took away

- The harness around a model can matter as much as the model itself.
- Evaluating what an agent builds, not just what it finishes, rewards lasting improvements.
- Read the paper to see how the harness quality is actually measured.
