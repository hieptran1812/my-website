## Summary

The author claims China just released a desktop automation agent that runs 100% locally. It can operate any desktop app, open files and browse websites without internet, and is open source.

## Background

A computer-use agent looks at the screen and clicks and types like a person. Running locally keeps data on your machine. The claim of working fully offline should be verified.

## What I took away

- Local agents help privacy.
- Verify claims like 100% offline by trying it.
- Be careful what permissions you give a desktop agent.
