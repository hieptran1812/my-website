## Summary

The author built Mission Strawberry, a small game where players try to write questions that people can answer but frontier LLMs cannot. The game gives a sense of what models can and cannot do. It also crowdsources a private benchmark.

## Background

A benchmark is a set of test questions used to measure models. Keeping it private helps avoid contamination, where models see test items in training.

## What I took away

- Human-easy, model-hard questions reveal real gaps.
- Private benchmarks resist training-data leakage.
