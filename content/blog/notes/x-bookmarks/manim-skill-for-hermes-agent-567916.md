## Summary

Nous Research introduces a Manim skill for Hermes Agent. Manim is an engine for precise programmatic animations for math and technical explainers, made famous by 3Blue1Brown.

## Background

Manim lets you write code that renders animated math videos. A skill is a packaged capability an agent can call. Together the agent can generate explanatory videos from a prompt.

## What I took away

- Agents can produce visual explainers by writing code.
- Skills extend agents without retraining.
- Manim is a good tool for technical teaching videos.
