## Summary

The author claims Claude Code can now copy any UI on the internet. It scans real websites and rebuilds their design system instantly, giving a starting point for your own project.

## Background

A design system is the set of colors, fonts and components behind a site. An agent can read the page and recreate these. Copying others' designs closely can raise legal and ethical issues.

## What I took away

- Use it for inspiration, not exact copies.
- Check the claim yourself.
- Respect copyright and branding.
