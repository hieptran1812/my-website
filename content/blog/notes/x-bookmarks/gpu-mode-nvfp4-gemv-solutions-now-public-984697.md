## Summary

The author says the first problem of the GPU Mode hackathon, nvfp4 gemv, has ended and the solutions are public. They say there is a lot of valuable insight in the top solutions.

## Background

GEMV is matrix-vector multiplication, central to LLM decoding. NVFP4 is a 4-bit floating-point format on NVIDIA GPUs. Writing fast kernels for it is a specialist skill, so reading winning code is a good way to learn.

## What I took away

- Study the top kernels to learn optimization tricks.
- Low-precision formats change how kernels are written.
