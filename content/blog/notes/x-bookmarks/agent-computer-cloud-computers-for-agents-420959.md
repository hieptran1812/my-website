## Summary

The author introduces Agent Computer: cloud computers for AI agents that start in under 0.5 seconds with persistent disk, shared credentials and SSH access.

## Background

Agents that run code need a machine. Fast-start, persistent environments let them keep state between tasks.

## What I took away

- Agents need fast persistent sandboxes.
- Check credential handling.
- Startup time matters for loops.
