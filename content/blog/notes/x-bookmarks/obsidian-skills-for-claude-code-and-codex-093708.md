## Summary

The author says Obsidian plus AI is the new hot combo. They note that Obsidian's CEO, kepano, made multiple skills for Claude Code and Codex that can be used now for a codebase or a personal vault.

## Background

Obsidian stores notes as local markdown files, which agents can read and edit. Skills teach the agent how to handle Obsidian formats.

## What I took away

- Plain-text notes work well with agents.
- Try the skills on a copy of your vault first.
