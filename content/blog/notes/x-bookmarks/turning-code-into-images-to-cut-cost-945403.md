## Summary

@mervenoyann asks whether this was in DeepSeek. The quoted post describes cutting about 60% of Fable cost by turning code into an image and having the model OCR it, with a GitHub repo.

## Background

Vision inputs can pack many text tokens into fewer image tokens, which can cut cost. The model then reads the text from the image by OCR. Quality tradeoffs are unclear.

## What I took away

- Text-as-image compression can reduce token cost.
- Test accuracy on code before using.
- The 60% figure is the author's claim.
