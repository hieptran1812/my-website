## Summary

The author thinks a dynamic living model with neural memory is a great idea. The quoted post says one static model does not fit all, so they generate custom parameters for every input, promising instant personalization, better instruction following and flexibility.

## Background

Instead of one fixed set of weights, a generator produces weights tuned to each request. This resembles hypernetworks. The benefits are the authors' claims.

## What I took away

- Generating parameters per input is a path to personalization.
- Check the paper for evidence behind the claims.
