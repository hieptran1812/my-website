## Summary

@pk_iv introduces v4 of their CEO CLI. It has a PS2-style loading graphic rendered in the terminal, is powered by the Claude Agent SDK, and has 10+ Claude skills for email, calendar, HubSpot, Snowflake, Linear and nano banana graphics. They ask whether to open source it.

## Background

The Claude Agent SDK is a toolkit for building agents. Skills are packaged instructions an agent loads when needed. Packaging many work tools as skills turns a terminal into a personal assistant for business tasks.

## What I took away

- Skills are a modular way to give an agent access to work tools.
- A terminal UI can be a good front end for a personal agent.
- Consider access and permissions when connecting email and databases.
