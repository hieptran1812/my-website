## Summary

The author is brushing up on SmoothQuant concepts and used a visualization skill, installed with the hermes skills install official/creative/concept-diagrams command. The post is mostly an image of the visualization.

## Background

SmoothQuant is a quantization method that shifts difficulty from activations to weights so both can be quantized to 8-bit with less accuracy loss. It exists because activations have outliers that are hard to quantize.

## What I took away

- SmoothQuant moves outlier difficulty from activations into weights.
- Agent skills can generate concept diagrams for studying.
- Visual explanations help revise technical ideas.
