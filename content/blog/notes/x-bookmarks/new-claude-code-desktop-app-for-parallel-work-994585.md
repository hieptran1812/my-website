## Summary

The author announces a new version of Claude Code in the desktop app. It was redesigned from the ground up for parallel work and is faster. He says it has been his main way to use Claude Code for the last few weeks.

## Background

Parallel work means running several agent sessions at once. A desktop app can manage these more easily than a single terminal.

## What I took away

- Parallel sessions are a key workflow now.
- The author uses it daily.
- Try it for multitasking.
