## Summary

The author likes the use of Excalidraw as an MCP App and built an app with it and the GitHub Copilot SDK to visualize what a pull request changes in a codebase. They say it helps understand what a coding agent did and also works for architecture diagrams. The quoted post introduces Excalidraw in Claude as an MCP App.

## Background

MCP (Model Context Protocol) is a standard way for AI apps to connect to tools. MCP Apps let a tool show an interactive interface inside the chat. Visual diagrams of code changes can be easier to review than long diffs.

## What I took away

- Diagrams can make agent-made code changes easier to review.
- MCP Apps let tools render interfaces inside chat clients.
- Try generating architecture diagrams from a PR.
