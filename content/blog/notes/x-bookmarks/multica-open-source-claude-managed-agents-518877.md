## Summary

The author says they created an open source version of Claude Managed Agents and calls it Multica. The quoted announcement says Claude Managed Agents pairs an agent harness with production infrastructure to go from prototype to launch in days, in public beta.

## Background

A managed agent service runs the harness and infrastructure for you. An open clone lets you run it yourself.

## What I took away

- Self-hostable alternative.
- Compare features.
- Public beta is early.
