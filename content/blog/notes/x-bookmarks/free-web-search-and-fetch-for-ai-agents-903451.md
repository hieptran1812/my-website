## Summary

The author claims they have replaced Exa, Tavily, SerpAPI and Brave by letting agents search and fetch any webpage for free, with no subscriptions or quotas. They contrast this with competitors charging $7 per 1,000 searches and argue agents should not have to pay when humans search Google free. They credit TinyFish, and the post is cut off.

## Background

Agents that use the web need a search API to find pages and a fetch tool to read them. These APIs usually charge per query. A free service lowers cost, but it is worth asking how it is funded and how reliable it is.

## What I took away

- Treat claims of killing competitors as marketing.
- Ask how a free API is funded and what its limits are before depending on it.
- Search cost is a real line item for agent builders.
