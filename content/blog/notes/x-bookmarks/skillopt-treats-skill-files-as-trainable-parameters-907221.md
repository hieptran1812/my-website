## Summary

The author calls this the next level. The quoted post describes gradient-descent-like optimization for SKILL.md files, saying it is becoming a real part of the agent harness. SkillOpt is described as one of the first papers to treat markdown skill files as trainable parameters, with a proper optimization framework.

## Background

Skill files are markdown instructions an agent loads to do a task. Optimizing them means automatically improving the text based on results, instead of hand-tuning. It keeps the model weights unchanged.

## What I took away

- Prompts and skills can be optimized systematically.
- Harness quality can matter as much as the model.
- Try measuring a skill file against a test set before editing it.
