## Summary

The author says Alpoge admitted the 250,000 pages claim was a joke and listed four things he did wrong. These include that the page count was a joke, the Lean code is poor but compiles, he accepts criticism, and he wrote it too fast. The quoted post is Alpoge's own list.

## Background

Lean is a proof assistant that checks mathematical proofs by computer. A proof that compiles in Lean is machine verified, even if the code is messy. Page counts of formal code are not a measure of quality.

## What I took away

- Machine-checked does not mean elegantly written.
- Big numbers in headlines can be jokes taken literally.
- Read the original source before repeating a claim.
