## Summary

The author introduces Goldman Sachs GS-Quant, a Python quant toolkit made by Goldman Sachs. They promise a thread on what you need to know. The thread content is not in the text.

## Background

GS-Quant is an open Python library for working with financial data, derivatives and risk. Using it may require access to Goldman's data services for some features. Check the documentation for what works without an account.

## What I took away

- Open-source finance libraries are a way to learn quant tools.
- Check which features need paid access.
