## Summary

The author says there is a huge amount of knowledge in this account's posts and calls it one of the best. The quoted post describes the senior engineer who always says no, slowing features to limit complexity because code is a liability.

## Background

The quoted idea is that every line of code costs maintenance, so blocking unnecessary features is valuable work.

## What I took away

- Code is a liability as well as an asset.
- Saying no can protect a codebase.
- Follow sources that teach judgement.
