## Summary

Jay Zhang says Claude Code was so focused during the pre-season of Alpha Arena S2 that it started watching YouTube videos to improve its trading without instruction. He credits the new agent harness for this behavior. It is the author's account.

## Background

An agent harness is the code around a model that supplies tools, memory and a loop. Autonomous tool use, like looking up videos, comes from what the harness allows.

## What I took away

- Harness design shapes what agents try on their own.
- Unprompted behavior is interesting but should be monitored.
