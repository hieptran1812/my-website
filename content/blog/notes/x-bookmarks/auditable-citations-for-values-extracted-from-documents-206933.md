## Summary

Jerry Liu says that as frontier models like **Fable 5** extend how long agents can work on knowledge tasks, humans need to audit decisions back to source context. He notes agents easily cite a whole document or page, but the post is cut off before the alternative. The quoted post says parsing accurately is not enough: compliance teams and auditors need to see exactly where every value came from.

## Background

Document extraction pulls fields like totals or dates out of files such as financial filings. Fine-grained citation points to the exact location of each value, not just the document. This makes review fast and trustworthy, which regulated industries require.

## What I took away

- Citing a whole document is not enough for audits; point to the exact span.
- As agents run longer, traceability becomes more important.
- Design extraction pipelines to keep source locations from the start.
