## Summary

Alex Dimakis says persistent agents are arriving and calls the work very cool. The quoted post introduces **Headlong**, an open-source microharness for persistent, self-guided agents that think continuously, unlike reactive harnesses that sit frozen between requests or rely on cron jobs and heartbeats.

## Background

A harness is the code that runs an agent. Reactive harnesses respond to one task at a time. Persistent harnesses keep the agent running so it can plan and act on its own over time.

## What I took away

- Persistent agents change the design from request-response to continuous loops.
- Continuous agents need monitoring and budgets.
- Another bookmark discusses using idle tokens for tasks like testing.
