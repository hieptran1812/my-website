## Summary

The post quotes a claim that Alysa Liu revealed in an interview a definition of logistic regression: to relate independent variables to the probability of passing or failing, use the logistic function p = 1 / (1 + e^-(b0 + b1*x1 + ... + bn*xn)). The attribution looks like a joke or meme.

## Background

Logistic regression takes a weighted sum of inputs and squashes it into a probability between 0 and 1 using the sigmoid function. It is a basic classification model.

## What I took away

- Logistic regression = linear combination passed through a sigmoid.
- Verify odd attributions before trusting them.
