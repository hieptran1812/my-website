## Summary

Ryan Carson says he will download and try this as soon as he is back at his desk. The quoted post introduces Readout, a native macOS app giving a real-time overview of your dev environment and Claude Code config. It is local, needs no account, and is in beta.

## Background

Claude Code has settings, skills and hooks spread across files. A dashboard that shows them in one place helps you understand your setup.

## What I took away

- Visibility into agent config helps debugging.
- It is beta software; try it cautiously.
