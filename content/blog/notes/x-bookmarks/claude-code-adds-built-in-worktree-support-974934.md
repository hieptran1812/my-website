## Summary

Morgan Linton says Claude Code is in rocket ship mode. The quoted announcement says Claude Code now has built-in git worktree support, so agents can run in parallel without interfering and each gets its own worktree. The Desktop app already had it.

## Background

A worktree is an extra working copy of a repo on its own branch. It prevents parallel agents from overwriting each other.

## What I took away

- Use worktrees for parallel agent runs.
- Each agent should have an isolated branch.
