## Summary

StepFun announces that **Step 3.7 Flash** is free for 30 days for Hermes Agent users, thanking NousResearch. The quoted Nous post describes it as a new MoE vision-language model focused on agent efficiency, coding, search and multimodal work. The joking line asks what could go wrong.

## Background

Hermes Agent is an agent framework from Nous Research, and Nous Portal is its model access service. Free trials like this help model makers get usage and feedback from agent builders.

## What I took away

- Free trial windows are a cheap way to test a new model in an agent.
- Models are increasingly marketed on agent efficiency.
- Remember trials end; plan for costs before building on them.
