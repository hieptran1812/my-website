## Summary

The author says the article Think in Math. Write in Code. is so good. The quoted post says programming seems important for crystallization of ideas but does not seem to be the critical step, then links the same article.

## Background

The article argues that you should reason mathematically about a problem and use code to express and test it. Writing code forces ideas to be precise. The link has the full argument.

## What I took away

- Reason in math first, then code to make it precise.
- Code helps check understanding.
- Read the linked article at jmeiners.com.
