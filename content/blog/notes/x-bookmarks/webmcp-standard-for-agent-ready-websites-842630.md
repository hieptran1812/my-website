## Summary

Aakash Gupta says Google and Microsoft co-authored a spec that turns websites into APIs for AI agents. Browser agents now take screenshots, parse the DOM and guess buttons. The quoted post says WebMCP is in early preview, giving a standard way to expose structured tools for faster, more reliable actions.

## Background

DOM is the page structure of a website. Screenshot-based agents are slow and brittle. WebMCP lets a site declare tools an agent can call directly, much like an API.

## What I took away

- Structured tools beat screen scraping for reliability.
- Site owners may soon expose agent tools.
