## Summary

The author sent another batch of applications and says the free, open-source tool jev-job-search is very helpful, linking its GitHub.

## Background

Job search automation tools help track and send applications. Review any automation before using it with personal data.

## What I took away

- Open-source tools can help with job search.
- Review code before giving it your data.
- Do not spam low-quality applications.
