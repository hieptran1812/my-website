## Summary

The author jokes that everything is a world model if you squint hard enough. There is no further explanation in the post.

## Background

A world model is a system that predicts how an environment changes. The joke points out that the term can stretch to cover almost any predictive model, so its meaning gets vague.

## What I took away

- The term world model is used loosely.
- Ask what a model predicts and how before using the label.
