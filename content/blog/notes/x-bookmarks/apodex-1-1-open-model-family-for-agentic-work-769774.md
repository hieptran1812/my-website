## Summary

The author is surprised that Apodex appeared suddenly and is matching **Claude Fable 5** level benchmarks. The quoted post introduces **Apodex 1.1**, a model family built to scale agentic intelligence for professional work, with an open-source harness on GitHub and open weights on Hugging Face.

## Background

Agentic intelligence refers to a model's ability to plan and use tools over many steps to finish tasks. Releasing the harness along with weights helps others reproduce results, since agent scores depend heavily on the harness.

## What I took away

- Benchmark parity claims from a new lab need independent checks.
- Agent results depend on the harness, so test with the released harness and your own.
- Open weights plus harness make reproduction possible.
