## Summary

The author asks if you tried the new Claude Code renderer and shows how to enable it with CLAUDE_CODE_NO_FLICKER=1. The quoted announcement says it is experimental with tradeoffs, and most internal users prefer it. Another quoted user asks to fix scrolling and flickering before adding more features.

## Background

Terminal apps redraw text constantly, which can flicker. A new renderer changes how the screen updates. Experimental features come with tradeoffs.

## What I took away

- Set the env variable to try it.
- User feedback drives fixes.
- Stability complaints matter.
