## Summary

The author says they started **CS336**, Stanford's course on building language models from scratch. They have also been deep into Hopper's TMA and find tensor maps surprising.

## Background

CS336 teaches how to build an LLM end to end, from tokenization to training. TMA (Tensor Memory Accelerator) is a feature in NVIDIA Hopper GPUs that moves blocks of data between global and shared memory efficiently. Tensor maps are descriptors that tell TMA the shape and layout of the data to copy.

## What I took away

- CS336 is a strong public resource for learning LLMs end to end.
- Pairing model-level study with GPU-level study builds a full picture.
- TMA and tensor maps are worth learning for modern kernel writing.
