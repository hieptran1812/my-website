## Summary

The author lists humorous 2026 interview questions. Examples include what to do mid-refactor when the model says 8% context is left before auto-compaction, how to decide tasks between Claude, Codex GPT 5.2 xhigh and ChatGPT Pro, and describing a time you disagreed with an LLM.

## Background

Auto-compaction means the tool summarizes the conversation when the context window is nearly full, which can lose details. Choosing which model handles which job is now a real skill for developers. The post is a joke but points at real workflow skills.

## What I took away

- Managing context limits is now a daily skill with coding agents.
- Different models suit different tasks, so learn their strengths.
- Practice pushing back when an LLM is wrong.
