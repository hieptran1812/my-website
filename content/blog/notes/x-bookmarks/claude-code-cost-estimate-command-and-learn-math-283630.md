## Summary

The author says RIP coders and tells people to learn math. The quoted post describes a Claude Code /cost-estimate command that scans a codebase and compares market rates to estimate what a real team would have charged, listing about 2.8 years and 650k dollars without AI.

## Background

The estimate is produced by the tool and is not an audited figure. The headline reaction is opinion. Estimating effort from code is rough at best.

## What I took away

- Treat auto-generated cost estimates as rough.
- Opinions about coding being dead are claims, not facts.
- Math skills remain broadly useful.
