## Summary

The quoted post says one of the author's favorite Codex and ChatGPT features is undocumented and was found on Reddit. They wanted to run Codex on a GPU Slurm cluster over SSH from their phone, and ChatGPT Desktop supports SSH connections. The author replies that the feature has not been officially released, which is why it is not in the main app menu.

## Background

Slurm is a job scheduler used on research GPU clusters. SSH lets you log in to remote machines securely. Running a coding agent on the cluster lets it work directly where the GPUs and data are.

## What I took away

- Unreleased features may change or vanish; do not depend on them.
- Running agents next to your compute avoids copying data around.
