## Summary

The author says to add a Tasks section to ~/.claude/CLAUDE.md. It tells Claude to auto-create tasks when work has three or more steps, dependencies, or touches multiple files, and always when spinning up subagents.

## Background

CLAUDE.md is a file of standing instructions for Claude Code. A shared task list gives subagents one place to see what is done and what is blocked, which reduces duplicate or lost work.

## What I took away

- Put task-creation rules in CLAUDE.md.
- Always create tasks when using subagents.
- Try thresholds like three or more steps.
