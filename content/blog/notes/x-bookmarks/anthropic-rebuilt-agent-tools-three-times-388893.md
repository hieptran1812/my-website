## Summary

The author praises an article by a Claude Code engineer. They say Anthropic rebuilt its tool system three times because the models outgrew it. The takeaway they stress is to design for how the models see, not how you see.

## Background

An agent harness gives a model tools such as file access or search. As models improve, old tool designs can limit them, so tools may need redesign around what the model handles well.

## What I took away

- Design tool interfaces from the model's viewpoint.
- Revisit tool design as models improve.
- Read the original article for details.
