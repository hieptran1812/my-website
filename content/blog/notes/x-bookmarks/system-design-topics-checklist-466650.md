## Summary

@makakmayum_sid lists system design topics to be able to explain: gRPC, CDNs, WebSockets, rate limiting, API gateways, microservices, Redis caching, load balancers, message queues, database sharding, consistent hashing, eventual consistency, distributed tracing and horizontal scaling. The list continues beyond the text shown.

## Background

These are the building blocks of large web systems. For example, consistent hashing spreads data across servers so adding a server moves little data. Such lists are common interview study aids.

## What I took away

- Use the list as a self-quiz and explain each in your own words.
- Pair each concept with a real case where it is needed.
