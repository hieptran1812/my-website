## Summary

The author highlights ART (Agent Reinforcement Trainer), an open-source framework from OpenPipe for training agents with GRPO plus RULER, an automatic reward system. It removes the need to hand-craft reward functions.

## Background

GRPO is a reinforcement learning method that compares groups of sampled outputs. Designing reward functions is hard. An automatic reward system uses a model to score runs.

## What I took away

- Automatic rewards reduce manual reward design.
- ART is a candidate for agent RL experiments.
- Check reward quality to avoid reward hacking.
