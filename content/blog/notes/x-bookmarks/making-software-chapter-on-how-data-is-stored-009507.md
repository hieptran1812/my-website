## Summary

The author is excited about Making Software and praises Dan's work. The quoted post says SSDs use quantum tunnelling to store data and that RAM must be rewritten every 30ms, and links a chapter on how computers store data.

## Background

Flash storage traps electrons using tunnelling. DRAM cells leak charge, so they are refreshed constantly. Knowing this helps in understanding memory performance.
