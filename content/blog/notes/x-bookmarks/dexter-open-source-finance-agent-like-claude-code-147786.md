## Summary

The author has built Dexter for 2 months, describing it as Claude Code for finance. It can find undervalued stocks, analyze them in detail and build an investment thesis. The code is open source and Dexter can also run on local LLMs.

## Background

A coding agent like Claude Code uses an LLM with tools to carry out tasks in a loop. Dexter applies the same pattern to financial research. Running on local LLMs means the models run on your own machine instead of a cloud API. Its output is research support, not advice.

## What I took away

- The coding-agent pattern can be adapted to other domains.
- Open source plus local models gives privacy and control.
- Verify any agent's financial analysis yourself.
