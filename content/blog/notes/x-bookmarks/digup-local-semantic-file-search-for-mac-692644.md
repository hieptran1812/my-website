## Summary

@googlegemma introduces DigUp, an open-source macOS menu bar app powered by EmbeddingGemma 2 that brings fully local, multimodal semantic search to your Mac. Instead of searching by file name, you can use natural language to find files by meaning.

## Background

Semantic search uses embeddings, vectors that capture meaning, to find content similar to a query even with different words. Running it locally keeps files private. Multimodal means it can index images as well as text.

## What I took away

- Small embedding models are enough for useful local search.
- Local processing avoids sending private files to the cloud.
- This is a good small project pattern: embeddings plus a vector index plus a simple UI.
