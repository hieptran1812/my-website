## Summary

Unusual Whales says it gave Claude access to the entire options and stock market through its MCP Server. It plugs into any AI assistant and offers live, structured market data on demand, so you can build a trading bot or finance dashboard.

## Background

MCP (Model Context Protocol) is a standard that lets AI assistants call external tools and data sources. A market data MCP server lets the model query live data instead of guessing. This describes a tool, not advice.

## What I took away

- MCP servers turn data APIs into tools an assistant can call.
- Live data reduces hallucinated numbers.
- Automated trading carries real risk; test carefully.
