## Summary

The author introduces AutoVoiceEvals, which applies the autoresearch loop to voice AI agents. A voice agent's system prompt determines how it handles bookings, complaints, edge cases, background noise and long pauses. The tool is open source. The text is cut off.

## Background

Evals are tests that score an agent's behavior. Here the loop tries prompt changes and keeps those that score better. Voice agents face messy real-world inputs, so automated testing is useful.

## What I took away

- System prompt changes can be tested automatically with evals.
- Voice agents need tests for noise, pauses and edge cases.
