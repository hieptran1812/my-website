## Summary

The author says Nano Banana Pro is great at ads, but prompting one image at a time wastes time. They built **The Ad Machine** with Google AI Studio and Gemini 3.0 to turn one product upload into endless 4K ad variations, starting with auto-prompting.

## Background

The tool uses one model to write prompts and another to generate images, so the user does not hand-craft each prompt. This pattern of auto-prompting is common in image pipelines.

## What I took away

- Let one model write prompts for another.
- Automating repeated manual steps is a good use of AI tools.
