## Summary

Mark Saroufim says they want to free researchers from systems work so they can focus on research again. The quoted post says his MLSys keynote on AI writing systems code drew more interest than expected, so they are starting the Core Automation Blog with this write-up while the recording is pending.

## Background

Systems code includes things like GPU kernels and training infrastructure that slow down researchers. The idea is that AI could write much of that code. MLSys is a conference on ML and systems.

## What I took away

- AI-written systems code is a live research direction.
- Read the blog post for the keynote's arguments.
- Reducing infrastructure burden could speed up research.
