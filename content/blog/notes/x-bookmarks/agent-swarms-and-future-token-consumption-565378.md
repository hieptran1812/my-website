## Summary

The quoted post says Prime Agent orchestrated a swarm of over 2,000 agents over two weeks to rewrite itself in Rust, using 10,000+ sandboxes, 200B+ GLM-5.3 tokens and 16,000 agent-to-agent messages. @levie says this shows where future tokens will be consumed, predicting agent swarms will have big implications in software, cyber, life sciences, AI research and finance.

## Background

An agent swarm is many AI agents working in parallel and messaging each other to finish a large task. Sandboxes are isolated environments where agents run code safely. Such runs use huge token volumes.

## What I took away

- Large multi-agent runs need serious infrastructure like sandboxes and messaging.
- Token demand may shift toward long-running agent workloads.
- Coordination between agents is a core engineering challenge.
