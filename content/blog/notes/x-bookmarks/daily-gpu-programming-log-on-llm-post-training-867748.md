## Summary

@levidiamode logs day 302 of 365 of GPU programming, watching lecture 14 of an efficient AI computing course on LLM post-training: efficient reasoning RL training, RLHF, DPO, DeepSeek R1 Zero and final project ideas. The quoted day 301 post covered lecture 12 on LLM deployment, including vLLM and paged attention, from the MIT efficient ML course.

## Background

RLHF trains models using human preference feedback; DPO is a simpler method that learns from preference pairs without a separate reward model. Paged attention is vLLM's way of managing KV cache memory in blocks.

## What I took away

- A daily learning log is a simple way to stay consistent.
- The MIT efficient ML course covers both serving and post-training.
- Learn deployment and training topics together; they inform each other.
