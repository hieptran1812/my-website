## Summary

The author calls Claude Code Agent Teams Anthropic's most important update and recommends an article covering agent teams vs sub-agents, how they work, how to enable them, what tasks suit them, and best practices.

## Background

A sub-agent is a helper the main agent spawns for a task. Agent teams have several agents working in parallel and coordinating. This suits large tasks that can be split.

## What I took away

- Parallel agents suit tasks that split into parts.
- Importance claim is the author's opinion.
- Read the article before enabling it.
