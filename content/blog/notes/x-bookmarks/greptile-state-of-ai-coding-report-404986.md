## Summary

Greptile announces its first annual State of AI Coding report. The company says it reviews a billion lines of code a month written by many coding agents, so it has a lot of data, and the report compiles interesting trends it saw.

## Background

Code review tools see the output of many coding agents, which gives a view of how AI-written code looks in practice. Such vendor reports can reveal trends but reflect the vendor's own customers. The post does not list the findings.

## What I took away

- Vendor data can show real trends in AI-written code.
- Keep in mind that the sample comes from one company's users.
- Open the report for the actual findings.
