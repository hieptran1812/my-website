## Summary

Claude Code Security is in limited research preview. It scans codebases for vulnerabilities and suggests targeted patches for human review, aiming to find issues traditional tools often miss.

## Background

Static tools match known patterns. An LLM can reason about code flow. Human review of patches remains in the loop.

## What I took away

- Human review stays required.
- Compare with existing scanners.
