## Summary

The authors introduce an interactive tutorial titled **Speculative Decoding: How It Evolved, When It Stays Lossless, and What's Next**, built for the NeurIPS Education Track. It starts from the fact that every LLM generates one token at a time; the rest is cut off.

## Background

Speculative decoding means a small model drafts several tokens and the big model checks them in one pass. Lossless means the output distribution is exactly the same as the big model alone. Interactive tutorials let you play with parameters to build intuition.

## What I took away

- Use this tutorial as a clear introduction to speculative decoding.
- Learn the conditions that keep it lossless before using relaxed variants.
