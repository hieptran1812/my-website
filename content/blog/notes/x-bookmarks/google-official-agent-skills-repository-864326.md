## Summary

Google Cloud says its official Agent Skills repository is available on GitHub. Agent skills equip agents with additional, condensed expertise, and more skills are promised in the coming weeks and months.

## Background

A skill is a packaged set of instructions an agent loads when needed, so it does not carry all knowledge in every prompt. An official repo gives a reference set to reuse.

## What I took away

- Skills are a reusable way to extend agents.
- Study official examples for good structure.
