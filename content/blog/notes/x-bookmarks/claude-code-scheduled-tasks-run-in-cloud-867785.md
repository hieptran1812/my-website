## Summary

The author says Claude Code on web has scheduled tasks that run in the cloud, so you can close the tab. The quoted post explains that you set a repo or repos, a schedule and a prompt, and Claude runs it on cloud infrastructure so your local machine need not stay on.

## Background

Scheduled tasks are like cron jobs for an AI agent: it runs a saved prompt on a timetable. Running in the cloud removes the need for a local session. Good uses include recurring checks or maintenance.

## What I took away

- Recurring agent work no longer needs your laptop running.
- Define a repo, schedule and prompt clearly for reliable results.
- Review agent output regularly since no one watches it run.
