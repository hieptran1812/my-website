## Summary

The author says the LLM space benefits from strong tech reports, while the diffusion community lacks them a bit. Photoroom decided to change that by releasing PRX under Apache 2.0 with solid reporting.

## Background

Apache 2.0 is a permissive open-source license that allows commercial use. A detailed tech report explains data, training choices and ablations, so others can reproduce and learn from the work. That openness speeds up the whole field.

## What I took away

- Open weights with a real report are more useful than weights alone.
- PRX is a resource for learning how diffusion models are trained.
- Check the Apache 2.0 license terms before using it.
