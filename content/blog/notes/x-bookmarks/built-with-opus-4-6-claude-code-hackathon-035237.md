## Summary

The Claude account announces **Built with Opus 4.6**, a Claude Code virtual hackathon. Participants join the Claude Code team for a week of building, and winners are hand-selected to receive $100K in Claude API credits. Applications are via a Cerebral Valley link.

## Background

Hackathons are a way for labs to find new uses for a model. API credits let winners keep building at no cost.

## What I took away

- Hackathons give a deadline to ship something.
- Check eligibility and dates on the page.
- Credits help prototype.
