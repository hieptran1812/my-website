## Summary

Alibaba Qwen thanks Unsloth and calls Qwen3-Coder-Next a cost-effective coding agent you can run locally. The quoted post says its GGUF is now the most downloaded model on Unsloth, and the 80B coding model runs on a 36GB RAM Mac or device, usable through Claude Code and Codex.

## Background

GGUF is a quantized model format for local inference. Running an 80B model in 36GB needs heavy quantization and likely a mixture-of-experts design.

## What I took away

- Large coding models can run on a laptop-class machine.
- Quantization quality should be tested.
