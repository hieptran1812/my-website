## Summary

Boris Cherny says he is a big fan of teaching more people the basics of Claude Code in an accessible way, noting much of the world has not used agents. The quoted post introduces zero2claude, a free course from zero terminal experience to shipping with Claude Code, with 17,000+ students.

## Background

Claude Code is Anthropic's coding agent in the terminal. The course covers software basics and then Claude Code fundamentals and advanced use. Beginner resources widen access to agent tools.

## What I took away

- Free structured courses help beginners start with coding agents.
- Basics of the terminal still matter for agent tools.
- Share resources with people new to agents.
