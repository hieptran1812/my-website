## Summary

The post introduces the supermemory CLI. It says MCP isn't dead but CLIs can be more powerful, and that everything possible on the platform can be done by agents, treated as first-class users. You can try it with npx supermemory.

## Background

MCP is a protocol for exposing tools to models. A CLI exposes the same actions as terminal commands, which coding agents already use well. This is the company's argument for its own product.

## What I took away

- CLIs are a simple tool interface for coding agents.
- Design products so agents are first-class users.
