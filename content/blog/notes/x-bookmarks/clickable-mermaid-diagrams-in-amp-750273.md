## Summary

The author says Mermaid diagrams in AmpCode are now clickable and links the news post.

## Background

Mermaid is a text format for drawing diagrams such as flowcharts. Coding agents like Amp often explain code with Mermaid diagrams. Making the nodes clickable lets users jump from a diagram to the related code or detail.

## What I took away

- Diagrams from agents are more useful when they link to the code.
- Mermaid is a handy format for agent-generated diagrams.
