## Summary

Tim Duffy reports that Gemma 3 27B has an SAE feature for Claude in layer 40, found in Gemma Scope 2. The post gives no more detail.

## Background

Gemma Scope is a set of sparse autoencoders trained on Gemma models, which break activations into interpretable features. A feature tied to the word Claude suggests the model has a concept for that name. This is a light observation, not a study.

## What I took away

- SAE tools let you search a model for concepts it represents.
- One feature hit is an anecdote; verify with examples before drawing conclusions.
