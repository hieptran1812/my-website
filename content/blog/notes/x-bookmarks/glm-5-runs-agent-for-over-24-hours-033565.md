## Summary

The Z.ai account shares a blog post titled GLM-5, Gameboy and Long-Task Era. It reports 700+ tool calls, 800+ context handoffs, and a single agent running for over 24 hours.

## Background

Long-task agents work for hours by calling tools many times. A context handoff means passing a summary of earlier work into a fresh context window, because a model can only hold so much text at once. Handling handoffs well is key to very long tasks.

## What I took away

- Long-running agents depend on good context management.
- Tool call count and run length are now used to show agent endurance.
- Read the linked blog for how the task was set up.
