## Summary

The author made Claude Code and Codex talk to each other with no APIs or special protocol, just a terminal. smux lets agents create, read and act on terminals, making the terminal a shared interface.

## Background

Agent-to-agent communication usually needs a protocol. Using terminals reuses a universal interface that any CLI agent already understands.

## What I took away

- Terminals can replace custom protocols.
- Different agents can collaborate.
- Watch for loops and permissions.
