## Summary

Solana announces its docs are LLM-ready. Adding .md to any docs URL returns the page in Markdown, for example solana.com/docs/core.md.

## Background

Markdown is plain text that is easy for LLMs to read, unlike HTML with heavy layout. Serving docs this way makes them cheaper and cleaner to put in a prompt or feed to a coding agent. More sites are adding similar options.

## What I took away

- Try appending .md to doc URLs when feeding docs to an LLM.
- Clean text input improves agent results and cuts tokens.
- Consider offering Markdown versions of your own docs.
