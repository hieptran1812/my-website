## Summary

The post points to the bytedance/deer-flow GitHub repository and promotes the author's newsletter. The link card describes it as an open-source long-horizon SuperAgent harness that researches and more.

## Background

A harness is the software around a model that gives it tools, memory and a loop so it can work on long tasks. Long-horizon means the agent works through many steps over time.

## What I took away

- DeerFlow is a repo to study for agent harness design.
- Read the repo to see how it handles long tasks.
