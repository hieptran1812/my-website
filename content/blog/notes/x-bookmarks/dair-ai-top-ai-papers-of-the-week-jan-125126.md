## Summary

@dair_ai lists the top AI papers of the week of January 12-18. They include UniversalRAG, Agent-as-a-Judge, Self-Evolving Search Agents, Active Context Compression, Efficient Lifelong Memory for LLM Agents, Extending Context by Dropping Positional Embeddings, and Unified Long-Term and Short-Term Memory.

## Background

RAG means retrieval-augmented generation, where a model looks up documents before answering. Agent-as-a-Judge uses an agent to evaluate other work. The list shows research trends around memory and context. Weekly digests save time for keeping up.
