## Summary

The post is a single prompt: design a distributed message queue. There is no answer in the text.

## Background

A message queue lets services send messages to each other asynchronously. A distributed one must handle partitioning, replication, ordering, delivery guarantees and failures. It is a common system design interview topic.

## What I took away

- Think through partitions, replication and delivery semantics.
- Decide between at-least-once and exactly-once delivery.
- Practice sketching the design before reading answers.
