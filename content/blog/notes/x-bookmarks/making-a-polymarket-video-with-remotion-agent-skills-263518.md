## Summary

@__Talley__ says video editors are cooked and that they made a video for Polymarket in 30 minutes with 4-5 prompts. The quoted post says Remotion now has Agent Skills so you can make videos just with Claude Code, installed with npx skills add remotion-dev/skills.

## Background

Remotion makes videos from React code. Agent skills are packaged instructions that let a coding agent do a task. Together they let a prompt produce an animation as code. The claim about editors is the author's opinion.

## What I took away

- Videos as code can be generated by agents.
- Skills package repeatable workflows.
- Treat the video editors are cooked claim as hype.
