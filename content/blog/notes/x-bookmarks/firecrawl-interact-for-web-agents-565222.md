## Summary

Firecrawl says agents can automate web actions with /interact. It lists clicking buttons, filling forms and navigating pages, extracting content behind interactions, and reusing browser state with persistent profiles.

## Background

Web scraping tools usually fetch static pages. Interaction lets agents handle logins and dynamic pages. Persistent profiles keep cookies and sessions between runs.

## What I took away

- Agents need browser actions for dynamic sites.
- Persistent profiles help with logged-in tasks.
- Be careful about credentials and terms of service.
