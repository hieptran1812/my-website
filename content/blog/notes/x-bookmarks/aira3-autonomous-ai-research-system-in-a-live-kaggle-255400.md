## Summary

The author outlines the AIRA series: AIRA1 for understanding the problem, AIRA2 for scaling, and AIRA3, which they claim surpasses experts on unhackable live tasks on the path to real recursive self-improvement. The quoted post says AIRA3 entered a live Kaggle competition run by NVIDIA in June to fine-tune a 30B Nemotron model to reason; the rest is cut off.

## Background

An autonomous AI research system is an agent that runs ML experiments by itself. Live competitions are harder to game than static benchmarks because the test data is hidden and fresh. RSI (recursive self-improvement) means AI improving AI research itself.

## What I took away

- Live, hidden-test tasks are a better check for research agents than static benchmarks.
- Treat surpassing-expert and RSI claims as the authors' framing.
- Read the papers to see how each AIRA version improved.
