## Summary

The Hermes Agent Creative Hackathon starts now and runs 16 days with $25k in prizes. It is presented by Kimi Moonshot and Nous Research. It is for people pushing Hermes Agent into creative areas such as video, image, audio, 3D and long-form writing.

## Background

Hermes Agent is an agent project from Nous Research. A themed hackathon encourages new uses and shows what the agent can do in creative work.

## What I took away

- Creative uses of agents are a focus here.
- Prizes and time limit make it a good prompt to build something.
- See the sibling post for submission rules.
