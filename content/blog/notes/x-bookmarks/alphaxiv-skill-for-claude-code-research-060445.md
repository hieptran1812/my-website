## Summary

The post advises not making Claude Code read directly from PDFs. alphaXiv introduced a SKILL.md that fetches structured, AI-friendly paper overviews.

## Background

PDFs are messy for models because layout, equations and figures break text extraction. A structured overview is cleaner and cheaper in tokens. A SKILL.md is a file that teaches an agent a reusable capability.

## What I took away

- Feed agents clean structured sources instead of raw PDFs.
- Skills are an easy way to add a data source to an agent.
