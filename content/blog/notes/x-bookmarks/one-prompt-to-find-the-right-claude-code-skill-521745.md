## Summary

The author says a Japanese developer found a simple Claude Code trick. Instead of browsing hundreds of skills, one prompt finds the best match for what you are building. The post does not show the prompt.

## Background

Claude Code skills are packaged instructions that the agent can load for a type of task. With many skills available, picking the right one is hard. A search or matching prompt could save time.

## What I took away

- Ask the agent to match skills to your task instead of browsing.
- The post is hype-style and shows no prompt, so test it yourself.
- Keep your own skill set small and well described.
