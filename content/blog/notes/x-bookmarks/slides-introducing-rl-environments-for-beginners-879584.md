## Summary

The author recommends a set of slides for anyone exploring RL environments for the first time. The slides, titled RL environments 101, are hosted as a Hugging Face Space.

## Background

An RL environment is the world an agent acts in: it gives observations, accepts actions and returns rewards. For LLM training, environments can be coding tasks, games or tool-use scenarios. Building good environments is a core part of modern agent post-training.

## What I took away

- Learn how environments define rewards before training agents with RL.
- Beginner slides are a quick way to get the vocabulary.
