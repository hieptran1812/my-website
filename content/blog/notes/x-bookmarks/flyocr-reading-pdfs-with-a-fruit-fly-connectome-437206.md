## Summary

The author introduces **FlyOCR**, describing it as training a fly brain to read a PDF. It uses the full MaleCNS v1.0 fruit fly connectome, with architecture inspired by doomfly. The system splits a PDF image into glyphs, maps pixels to receptor activations, and runs a simplified simulation; the rest is cut off.

## Background

A connectome is a full wiring map of neurons in a brain. OCR is optical character recognition, turning images of text into text. Using a real connectome as a network is mostly an experiment or demo, not a replacement for standard OCR models.

## What I took away

- Biological wiring diagrams can be used as fixed neural network structures for fun experiments.
- Treat it as an exploratory project, not a production OCR tool.
