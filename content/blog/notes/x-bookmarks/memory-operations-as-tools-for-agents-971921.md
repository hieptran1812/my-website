## Summary

Karpathy recalls a time when researchers discussed ideas openly on Twitter, and guesses you can get far in the current paradigm by adding memory operations as tools. He is replying to a post about continual learning for long-running agents, where prompt compaction and recursive sub-agents work remarkably well.

## Background

Giving an agent tools to read, write and edit memory lets it manage its own context. This avoids retraining while still offering a form of learning over time.

## What I took away

- Expose memory read and write as agent tools.
- Plain prompting techniques may deliver continual learning without new training.
- Related to the Agentic Memory work in another bookmark.
