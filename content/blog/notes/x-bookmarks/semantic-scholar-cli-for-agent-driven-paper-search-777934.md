## Summary

Niels Rogge shows an answer to what the most impactful papers of 2026 are, produced by paperswithcode.co chat using the new Semantic Scholar CLI. The quoted post says Semantic Scholar is a rich source of citation data and now has an easy CLI and skill, so you can ask an agent things like find all papers that cite the DeepSeek-R1 paper.

## Background

Semantic Scholar is a free academic search engine with citation graphs. A CLI (command-line tool) and skill package let coding agents call it directly. Citation counts are a rough proxy for impact.

## What I took away

- Agents with a citation tool can do quick literature surveys.
- Citation-based impact rankings favor older and more hyped papers.
- Try asking for papers that cite a key work to map a research area.
