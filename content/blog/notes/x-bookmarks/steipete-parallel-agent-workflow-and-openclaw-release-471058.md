## Summary

The author says OpenClaw founder steipete runs 4-10 AI coding agents in parallel and claims 500+ commits per day and 6,600+ in January. The quoted release 2026.3.22 adds a plugin marketplace, MiniMax M2.7, GPT-5.4-mini/nano, SSH sandboxes and search tools.

## Background

Parallel agents work on separate tasks at once, with the human reviewing. Commit counts are a weak productivity measure.

## What I took away

- Parallel agents multiply throughput.
- Commit counts are not quality.
- Reviewing is the new bottleneck.
