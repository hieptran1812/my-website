## Summary

The post shares the mini-omni GitHub repository, described as a streaming speech-to-speech language model.

## Background

A speech-to-speech model takes spoken input and replies in speech without a separate text pipeline. Streaming means it starts speaking before finishing the full reply, which lowers latency. The post gives no benchmarks.

## What I took away

- Streaming output cuts waiting time in voice assistants.
- Check the repo for model size and license before using.
