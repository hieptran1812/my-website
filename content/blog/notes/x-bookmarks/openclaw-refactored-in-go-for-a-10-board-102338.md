## Summary

DataChaz says Chinese engineers refactored OpenClaw in Go. He claims it runs on a $10 Raspberry Pi instead of a $399 Mac mini, uses under 10MB of memory, starts 400x faster and boots in 1 second. It is free and open source.

## Background

Go builds small compiled programs. If the model runs remotely, the agent program mostly handles messages and tools, so it can be tiny. Figures are the author's claims.

## What I took away

- Lean agents can run on cheap hardware.
- Check the repo for actual numbers.
