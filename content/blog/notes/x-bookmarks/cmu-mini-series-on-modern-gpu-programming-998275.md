## Summary

@zhzHNN calls the material unbelievable and thanks the authors. The quoted post says a new mini-series on Modern GPU Programming for ML Systems was taught at CMU, covering data layout swizzling, 3D TMA and state-of-the-art Blackwell programming, with a curated collection released.

## Background

Data layout swizzling reorders memory layout to avoid bank conflicts. TMA is a hardware engine for async tensor copies on recent NVIDIA GPUs. Blackwell is NVIDIA's newest GPU generation.

## What I took away

- Free course material on current GPU programming exists.
- Swizzling and TMA are key topics for fast kernels.
