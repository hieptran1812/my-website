## Summary

The author played with generating the internal anatomy of a creature, including skeletons and organs. GPT Images 2 kept the anatomy consistent, while code, interactions and 3D models were generated with omma_ai and rendered with three.js.

## Background

Three.js is a JavaScript library for 3D graphics in the browser. Combining an image model for consistent visuals with code generation for interactivity is a common workflow for AI-assisted prototypes.

## What I took away

- Pair an image model for look consistency with code generation for interaction.
- three.js is a handy target for AI-generated 3D demos.
