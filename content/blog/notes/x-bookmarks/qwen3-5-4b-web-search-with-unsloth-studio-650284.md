## Summary

Unsloth says Qwen3.5-4B searched 20+ websites, cited its sources and found the best answer. You can try it locally with just 4GB RAM via Unsloth Studio. The 4B model made tool calls and web searches directly during its thinking trace.

## Background

A thinking trace is the reasoning a model writes before answering. Calling tools inside it lets a small model look things up as it reasons. Small models plus tools can handle research tasks on modest hardware.

## What I took away

- Tool use inside reasoning makes small models more capable.
- 4GB RAM is enough to try this locally.
