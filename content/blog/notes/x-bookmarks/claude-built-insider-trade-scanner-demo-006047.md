## Summary

The author says Claude built an insider trades scanner in 4 minutes. It reads SEC filings where executives buy their own stock, flags clusters, and emails the top 3 trades each morning. The quoted post says Xynth wires Claude Opus 4.7 and Python to 3,000+ market endpoints for custom alerts.

## Background

Insider purchase filings are public. A scanner that monitors them is a data pipeline an LLM can write. Seeing a filing is not a recommendation to trade.

## What I took away

- LLMs can build monitoring pipelines on public data fast.
- This is an automation example, not trading advice.
