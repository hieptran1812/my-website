## Summary

@SimWeberTUM announces a poster on Functional Attention. The quoted post asks what if attention was about operating in function space, and presents the paper Functional Attention: From Pairwise Affinities to Functional Correspondences.

## Background

Standard attention scores how well each token pair matches. Functional attention instead maps between functions, treating relationships as correspondences. It is a proposed alternative view.

## What I took away

- Attention can be reframed beyond pairwise matching.
- Check the project page for details and results.
