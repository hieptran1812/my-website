## Summary

The author shares the **Trail of Bits** defaults for Claude Code. They say this is how the team sets up, configures, and uses Claude Code, with a link to a GitHub repo.

## Background

Claude Code is a coding agent that runs in your terminal and can be configured with settings, permissions and instruction files. A security firm's configuration is a useful reference for sensible defaults, especially around permissions and safe use.

## What I took away

- Reading a security team's config is a quick way to learn safer defaults.
- Review the repo and adapt settings to your own risk level.
- Shared configs are a good starting point for team-wide standards.
