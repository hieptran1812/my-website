## Summary

The author claims they cancelled CrowdStrike, Cloudflare and Okta to save over 4M a year and use Claude Code for security, then says they gave up sensitive user data and are being sued. The quoted post says an Anthropic blog post cut cybersecurity stocks by $10B in one hour.

## Background

The tone suggests satire. Replacing security vendors with a coding agent is not an accepted practice, and stock drops after announcements are not proof of causation.

## What I took away

- Be skeptical of dramatic claims.
- Security tools cover monitoring and identity, not only code scanning.
