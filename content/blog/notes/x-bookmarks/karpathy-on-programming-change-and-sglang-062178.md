## Summary

The author says typing code into an editor is over and programming is about setting constraints and reviewing trajectories. They say they use SGLang to keep agentic loops lean. The quoted post says programming changed a lot in the last 2 months, and that coding agents basically did not work before December.

## Background

SGLang is a serving framework for LLMs. The idea is to guide agents with constraints and review their output, not write everything by hand. The tool pitch is promotional.

## What I took away

- Review skill is becoming central.
- Verify claims about code reduction yourself.
