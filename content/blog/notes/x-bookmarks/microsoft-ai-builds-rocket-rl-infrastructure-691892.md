## Summary

Microsoft AI says reaching the frontier from a base model needs RL runs lasting weeks to months. It built its own RL infrastructure, called Rocket, and shares technical details in a linked post.

## Background

RL infrastructure coordinates model generation, scoring and weight updates across many GPUs. Making it stable for months-long runs is an engineering challenge, which is why labs build custom systems.

## What I took away

- Long RL runs need dedicated infrastructure.
- Read the linked post for design details.
- Compare with other labs' RL stacks.
