## Summary

Karpathy released the autoresearch project as a self-contained minimal repo. It is the nanochat LLM training core stripped down to a single-GPU, one-file version of about 630 lines. The human iterates on part of the setup, per the start of the list in the post.

## Background

Autoresearch means an AI agent runs experiments to improve a model training setup. Nanochat is a small LLM training codebase. Keeping the code tiny makes it possible to run and study over a weekend on one GPU.

## What I took away

- A roughly 630-line single-file setup is easy to read end to end.
- It is a good weekend project to understand automated research loops.
- Open the post for the full description of the human and agent roles.
