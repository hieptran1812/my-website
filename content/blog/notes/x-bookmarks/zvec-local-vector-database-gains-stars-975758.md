## Summary

Greptile says zvec runs inside your app and enables local RAG without a separate database, with vector search built in for local AI tools. It grew from 500 to 5,300 GitHub stars in a week.

## Background

RAG retrieves relevant documents using vector similarity and gives them to a model. An embedded database avoids running a separate server.

## What I took away

- Embedded vector stores simplify local apps.
- Stars show interest, not maturity.
