## Summary

The quoted post says GLM-5 has 744B total and 40B active parameters, trained on 28.5T tokens, for complex systems engineering and long-horizon agentic tasks, using DeepSeek Sparse Attention for cost-efficient long context.

## Background

Active parameters are used per token in a mixture-of-experts model. Sparse attention cuts long-context cost.
