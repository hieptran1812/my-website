## Summary

@hive_echo built a real-time genetic programming sandbox where each creature's brain is a tiny stack-based bytecode genome. They survive by answering arithmetic problems while evolution continues. The quoted post shows an online-learning world model mouse whose planned paths move toward the cheese after about 30 seconds of training.

## Background

Genetic programming evolves small programs by selection and mutation. A world model is a learned predictor of what happens next, which an agent can use to plan. Both are small, visual demos of those ideas.

## What I took away

- Small sandboxes are a good way to learn evolution and planning.
- A world model can be trained online in seconds on toy tasks.
- Code is shared in the comments for hands-on trials.
