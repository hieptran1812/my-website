## Summary

The post promotes a guide from Anthropic called The Complete Guide to Building Claude Skills. It lists topics: structuring the skill folder, what makes a skill trigger reliably and what breaks it, and writing clear SKILL.md instructions.

## Background

A skill is a folder with a SKILL.md file that tells an agent when and how to do a task. The description controls whether the skill is triggered. Good structure keeps context small.

## What I took away

- Skill descriptions drive reliable triggering.
- Keep SKILL.md instructions clear and focused.
- Read the official guide before writing your own skills.
