## Summary

The author, who has created over a hundred models like Tess and Synthia, releases his LLM fine-tuning recipe so anyone can build their own models. He says it has never been a better time to fine-tune and provides a skills repo.

## Background

Fine-tuning adapts a base model to a task or style. A skills repo packages instructions that coding agents can use to run the process.

## What I took away

- Fine-tuning is accessible.
- Agents can run recipes with skills.
- Review the repo before using.
