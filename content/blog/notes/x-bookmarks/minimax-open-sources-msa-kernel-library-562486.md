## Summary

@RyanLeeMiniMax says the MSA kernel library is open source and M3 weights are expected on Friday. He links GitHub and a paper on MiniMax Sparse Attention.

## Background

Kernels are low-level GPU programs. Open sourcing them lets others run the sparse attention model efficiently.

## What I took away

- Check the repo for kernels.
- Kernels decide whether an architecture is practical.
