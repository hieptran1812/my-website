## Summary

MiniMax announces MaxClaw, combining OpenClaw, MiniMax Agent and M2.5. It says there is no deployment and no extra API fees, runs 7x24 across Telegram, WhatsApp, Slack and Discord, and has a ready-made Expert ecosystem and upgraded tools.

## Background

Hosting an agent for the user removes server setup. The always-on chat integrations let the agent reply on messaging apps. It is a vendor announcement.

## What I took away

- Hosted agents trade control for convenience.
- Check data handling before connecting chats.
