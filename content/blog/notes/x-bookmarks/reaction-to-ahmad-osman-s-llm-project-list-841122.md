## Summary

@DanAdvantage reacts enthusiastically to a quoted post by Ahmad Osman and likens it to Karpathy-style teaching. The quoted post lists step-by-step LLM engineering projects, each teaching one concept the hard way, starting with tokenization and embeddings such as building a byte-pair encoder.

## Background

A byte-pair encoder is a tokenizer that merges frequent character pairs into subword tokens. Building one yourself shows how text becomes the numbers an LLM reads. Project-based lists like this teach by doing.

## What I took away

- Building each component yourself is a strong way to learn LLMs.
- Start with tokenization and embeddings, then move up the stack.
