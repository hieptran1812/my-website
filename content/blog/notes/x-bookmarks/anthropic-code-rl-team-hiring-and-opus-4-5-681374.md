## Summary

The author says they are hiring on the Code RL team at Anthropic, a small, fast-moving team seeking engineers and researchers for AI-powered software engineering. The quoted post introduces Claude Opus 4.5 as the best model in the world for coding, agents and computer use, which is Anthropic's own claim.

## Background

Code RL means using reinforcement learning to improve models on coding tasks, often with test results as rewards. Computer use means a model operating a computer through screenshots and clicks. The post is a recruiting message plus a product announcement.

## What I took away

- Code RL is an active hiring area.
- The best model claim is the vendor's own statement.
