## Summary

The author says xai-org/x-algorithm is public but almost nobody has read it, and that Scira X Studio does so before writing a post for you. The quote says the latest X algorithm was published to GitHub.

## Background

Social platforms rank posts with recommendation algorithms. Publishing the code lets people study what is favored. A tool that uses it claims to tailor posts, which is a product claim.

## What I took away

- Read the open source ranking code if you care about reach.
- Writing tools built on it are unproven; test them.
- Algorithms change, so findings may age fast.
