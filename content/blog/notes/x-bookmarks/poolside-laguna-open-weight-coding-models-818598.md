## Summary

NVIDIA congratulates Poolside on releasing Laguna XS.2 and Laguna M.1. The quoted post says XS.2 is Poolside's first open-weight model, 33B total and 3B active MoE, built for agentic coding and long-horizon tasks, trained in-house, runs on a single GPU, and is Apache 2.0.

## Background

A mixture-of-experts model has many parameters but activates only a few per token, so it is cheap to run for its size. Open-weight means the weights can be downloaded.

## What I took away

- MoE with 3B active gives strong size-to-cost tradeoffs.
- Single-GPU, Apache 2.0 models are easy to try.
