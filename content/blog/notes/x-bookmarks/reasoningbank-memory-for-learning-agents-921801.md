## Summary

Google Research describes **ReasoningBank**, a memory framework for LLM agents. It lets agents keep learning from both successful and failed experiences. The authors say their tests show better success rates and efficiency.

## Background

Most agents start every task fresh and forget what happened before. An agent memory stores lessons from past runs so it can reuse them later. Learning from failures too is useful because mistakes often teach more than wins.

## What I took away

- Store lessons from failed runs, not only successes.
- Memory is a key part of making agents improve over time.
- The gains are the authors' claim; read the paper for the numbers.
