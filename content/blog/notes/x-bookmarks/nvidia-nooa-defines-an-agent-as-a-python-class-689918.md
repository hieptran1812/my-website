## Summary

The author says NVIDIA is bringing object-oriented programming to AI agents with an open-source framework called **NOOA**. The idea is that an agent can be one Python class instead of being spread across prompt files, tool schemas, callbacks and a workflow graph. The text is cut off as it begins to describe how methods are used.

## Background

Object-oriented programming groups data and behavior into classes. Defining an agent as a class could mean methods become tools and the class holds the agent's state, keeping all parts in one place.

## What I took away

- Keeping agent definition in one place can make it easier to read and test.
- Map familiar software patterns onto agents where they fit.
- Check the repo for how prompts and tools are derived from the class.
