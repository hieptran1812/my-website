## Summary

The author introduces polymarket cli, built with Rust, as the fastest way for AI agents to access prediction markets. They say an agent can query markets, place trades and pull data from the terminal, with a lightweight design.

## Background

A CLI is a command-line tool. Agents can run commands easily, so a CLI is a simple way to give them access to a service. Letting agents place trades carries financial risk.

## What I took away

- CLIs are a simple interface for agents.
- Limit permissions if an agent can trade.
