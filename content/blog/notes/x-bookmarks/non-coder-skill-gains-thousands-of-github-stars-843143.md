## Summary

The author, a non-coder, says a skill they built got 5.8k GitHub stars and shows a presentation vibe coded with it. The quoted post is a 20-minute talk, Code as a Medium for Storytelling, with 5 projects and 7 lessons for working with coding agents.

## Background

A skill is a packaged set of instructions an agent can load. Vibe coding means building by prompting an AI instead of writing code.

## What I took away

- Non-coders can ship useful agent skills.
- The 7 lessons in the talk may be worth reading.
