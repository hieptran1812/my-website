## Summary

Sergio Paniego says he trained his own version using TRL and OpenEnv and will soon publish a blog with open code, models, dataset and RL environment. The quoted post says you can use RL on a coding model to make it paint with JavaScript.

## Background

TRL is a Hugging Face library for post-training LLMs, including reinforcement learning. OpenEnv is a framework for defining RL environments. Painting with code means the model writes JavaScript that draws an image, and the reward scores the resulting picture.

## What I took away

- RL works for creative tasks when you can score the output automatically.
- Open RL environments make experiments like this reproducible.
- Watch for the blog to see how the reward was designed.
