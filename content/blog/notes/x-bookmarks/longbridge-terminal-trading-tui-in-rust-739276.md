## Summary

The post shares longbridge-terminal, a TUI for stock trading and monitoring. It has real-time watchlists, candlestick charts and HK, US and CN markets. It is written in Rust with Ratatui and hosted on GitHub.

## Background

A TUI is a text-based interface running in the terminal. Ratatui is a Rust library for building them. Terminal tools are lightweight and scriptable.

## What I took away

- Ratatui is a good option for Rust terminal apps.
- Check broker support before use.
