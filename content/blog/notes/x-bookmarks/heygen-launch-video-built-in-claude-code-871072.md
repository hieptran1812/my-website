## Summary

HeyGen says it built its launch video in Claude Code using HyperFrames, an open-source, agent-native framework that turns HTML into MP4. It shares an install command and offers the full source to people who repost, comment and follow.

## Background

This is a demo that an agent can produce a polished video from code. The engagement offer is a marketing tactic.

## What I took away

- Agents can produce full videos from code.
- The framework is installable with npx skills.
- Giveaways drive reach.
