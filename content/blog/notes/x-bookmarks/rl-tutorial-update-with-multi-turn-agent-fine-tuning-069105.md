## Summary

The author announces another update to their reinforcement learning tutorial on arXiv. It now has code for RLFT (reinforcement learning fine-tuning) of multi-turn LLM agents, using the **Tinker** library from Thinking Machines and the simple **ReBN** training loop from GEM. The text is cut off after mentioning about 100 of something.

## Background

RL fine-tuning trains an LLM using reward signals instead of fixed answers. Multi-turn agents act over many steps, so rewards come late. A tutorial with working code helps readers go from theory to practice.

## What I took away

- The tutorial is a free, evolving RL reference.
- Try the multi-turn agent code to learn RL fine-tuning hands-on.
