## Summary

The author says **gpt-5.5** works well on hard tasks such as writing GPU kernels. The quoted post says KernelBench-Hard is coming soon. The post gives no results or numbers.

## Background

A GPU kernel is a small program that runs directly on the GPU, and writing a fast one needs deep hardware knowledge. A benchmark like KernelBench tests whether models can write correct and fast kernels. A harder version would show how far models have come at low-level performance work.

## What I took away

- Kernel writing is being used as a test of how strong a coding model is.
- This is the author's claim; wait for the KernelBench-Hard results to check it.
- Benchmarks for low-level performance code are worth following if you work on inference.
