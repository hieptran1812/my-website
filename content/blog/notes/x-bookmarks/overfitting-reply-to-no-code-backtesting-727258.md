## Summary

The author jokes that overfitting got cooked, quoting the post about backtesting everything without writing strategy code using OpenAlgo and VectorBT. The point is that easy backtesting invites overfitting.

## Background

Overfitting in trading means tuning to historical noise so results look great but fail live. More tests with less friction raise the risk.

## What I took away

- Easy testing multiplies overfitting risk.
- Use out-of-sample validation.
