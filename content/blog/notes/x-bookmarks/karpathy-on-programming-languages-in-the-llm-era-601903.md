## Summary

Karpathy says it is an interesting time for programming languages and formal methods, citing momentum for porting C to Rust. He quotes a post on supply chains and monoliths becoming more likely when rewriting code is cheap, and Anthropic's post about Opus 4.6 agent teams building a C compiler that worked on the Linux kernel.

## Background

If LLMs make rewriting and verifying code cheap, tradeoffs like dependence on libraries shift. Formal methods give machines checkable proofs.

## What I took away

- Cheap rewriting changes dependency decisions.
- Verifiable languages help agent output.
