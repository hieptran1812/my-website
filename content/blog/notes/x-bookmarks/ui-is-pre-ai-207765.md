## Summary

The author writes only that UI is pre-AI. They are implying that traditional user interfaces may be replaced as AI becomes common. No further explanation is given.

## Background

The idea is that if an AI agent can do tasks from plain language, menus and buttons matter less. This is a provocative opinion, not an established fact.

## What I took away

- Ask which tasks still need a visual interface.
- Treat one-line predictions as prompts for thinking.
