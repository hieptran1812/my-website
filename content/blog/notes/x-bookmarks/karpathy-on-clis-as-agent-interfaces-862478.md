## Summary

Karpathy says CLIs are exciting precisely because they are legacy technology, so agents can use, combine and interact with them through the terminal toolkit. He suggests asking Claude or Codex to install the new Polymarket CLI and use it. The quoted post introduces that CLI.

## Background

Old Unix-style tools have simple text input and output, so agents can chain them. This is often easier than building new custom integrations.

## What I took away

- Prefer CLIs when giving agents tools.
- Old interfaces can be agent friendly.
