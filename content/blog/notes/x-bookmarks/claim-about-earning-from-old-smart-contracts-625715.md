## Summary

The author says few know you can print millions by exploiting or fixing old smart contracts. The quoted post introduces Claude Code Security, in limited research preview, which scans code for vulnerabilities and suggests patches for human review.

## Background

Smart contracts are immutable code holding funds, so bugs are costly. Exploiting them is illegal; fixing via bounties is legitimate. The profit claim is unverified.

## What I took away

- Treat profit claims skeptically.
- Use scanners for defensive work.
