## Summary

@aditiitwt lists benefits students can get with a student ID. It names Cursor Pro, AWS Educate, GitHub Copilot, the GitHub Student Pack, Google Gemini Pro, Apple Music, YouTube Premium, Amazon Prime, flight booking offers and DigitalOcean credits. The list is cut off.

## Background

Many companies offer student pricing or free tiers. The GitHub Student Pack bundles many developer tools. Offers change and often need verification, so check each provider.

## What I took away

- Students can access paid tools cheaply or free.
- Verify each offer on the provider's page.
- Offers vary by region and change over time.
