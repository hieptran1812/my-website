## Summary

The author says Claude Code 2.1.90 adds a /powerup command that gives interactive lessons on using Claude Code within the tool. He finds it solid and is curious how the UI will look in VSCode.

## Background

Claude Code is Anthropic's terminal coding agent. In-tool tutorials help users learn features without leaving the workflow.

## What I took away

- Try /powerup to learn features.
- In-product lessons lower the learning cost.
- Check release notes for new commands.
