## Summary

The author asks if this invalidates natural language autocoders and activation lenses that Anthropic uses now. The quoted thread says we know LLMs can introspect and control internal activations, but they can do this with attention too.

## Background

Interpretability tools read a model's internal activations. If a model can deliberately shape those activations, readouts may be less trustworthy. Whether this applies is the author's question, not an answer.

## What I took away

- Models controlling activations could weaken probes.
- The post is a question, not a conclusion.
- Read the thread to see the evidence.
