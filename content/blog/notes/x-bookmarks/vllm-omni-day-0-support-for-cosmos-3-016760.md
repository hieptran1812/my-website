## Summary

vLLM says it partnered with NVIDIA on day-0 support for Cosmos 3 on vLLM-Omni. The model is a unified Mixture-of-Transformers fusing an autoregressive reasoner with a diffusion generator across text, image, video, audio and robot action, behind one OpenAI-compatible API.

## Background

Autoregressive models generate one token at a time, and diffusion models refine whole outputs. Combining them lets one system reason and generate media.

## What I took away

- One API can serve multimodal and action outputs.
- Day-0 support lowers the barrier to try it.
