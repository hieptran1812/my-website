## Summary

The author says that for ML Engineering roles in LLM applications, some obvious skills are often overlooked. The list includes cost optimisation, latency and throughput including TTFT, data pipelines, batch inferencing and evaluation. The text is cut off.

## Background

TTFT is time to first token, how long a user waits before output starts. Production LLM apps depend on cost, speed and measurement as much as on model quality. These skills are what teams hire for.

## What I took away

- Learn to measure latency, throughput and TTFT.
- Cost optimization is a real skill.
- Evaluation and data pipelines matter beyond prompting.
