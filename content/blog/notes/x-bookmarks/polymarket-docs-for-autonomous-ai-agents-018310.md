## Summary

The author tells people thinking about AI trading bots on Polymarket to read the official GitHub materials first. They say the repo explains how to trade autonomously using AI agents. The quoted post says the docs are all you need and adds NFA DYOR.

## Background

Polymarket is a prediction market where people trade on event outcomes. Official agent docs show how software can connect and place orders. NFA DYOR means not financial advice, do your own research. This is not a recommendation to trade.

## What I took away

- Read official docs before building any trading bot.
- Automated trading carries real risk of loss; test with no real money first.
