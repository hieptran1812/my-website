## Summary

The author set up their Mac and iPhone for coding with Codex or Claude Code on the go. They use tmux for persistent sessions, Tailscale for a private network, and Termius as an SSH client. Sessions stay in sync between iOS and macOS.

## Background

tmux keeps terminal sessions running even if you disconnect. Tailscale connects devices securely, and Termius is an SSH app. Together you can reattach to the same session from any device.

## What I took away

- tmux makes agent sessions survive disconnects.
- Tailscale avoids opening ports to the internet.
- The same pattern as other remote-access posts in this batch.
