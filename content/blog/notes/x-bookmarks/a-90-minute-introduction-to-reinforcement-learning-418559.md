## Summary

The author calls this one of the best introductions to reinforcement learning, in only 90 minutes. Topics include framing RL problems (agent, environment, states, actions, rewards), grid mazes with world models versus model-free methods, evaluation methods such as Monte Carlo, TD and SARSA, and scaling up with DQN and actor-critic. The quoted post says distributed systems and RL are two key skills for anyone in AI.

## Background

Model-free RL learns from trial and error without a model of the environment. Monte Carlo waits for full episodes to estimate value, while TD (temporal difference) updates from each step. DQN uses a neural network to estimate action values, and actor-critic methods learn a policy and a value estimate together.

## What I took away

- A short, well-structured course is a good way to refresh RL basics.
- Distributed systems and RL both matter for modern AI work.
- Learn TD versus Monte Carlo well; it underlies many RL methods.
