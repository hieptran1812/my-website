## Summary

Elon Musk says SFT is more like getting a haircut with a chainsaw than fine-tuning and should be built into primary training. He also says having a system prompt is silly and that default behavior should be sensible. He says this is already true for Tesla AI.

## Background

SFT is supervised fine-tuning, training on example outputs after pretraining. A system prompt is hidden text that steers the model. Musk argues behavior should come from the main training instead. This is an opinion, and the text is cut off.

## What I took away

- Debate exists on how much to fold post-training into pretraining.
- System prompts patch behavior; training changes it.
- This is one person's opinion.
