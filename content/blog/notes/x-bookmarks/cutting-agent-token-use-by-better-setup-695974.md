## Summary

The author claims Anthropic cut its agents' token use by 85% and raised them from 49% to 74% without a bigger model, and cites an engineer saying you spend tokens to set up a codebase so even weak agents do well. The quoted post says 75% of one Grok Bot's tokens went to re-reading old chat and about 1% to actual work, and lists 9 leaks.

## Background

Agent cost depends heavily on how much context is re-sent each turn. Good setup, such as clear repo docs and short contexts, reduces waste. The figures here are the posters' claims and the post uses hype language.

## What I took away

- Check how much of your agent spend goes to re-reading history.
- Invest in codebase setup so agents need fewer tokens.
- Treat headline percentages cautiously.
