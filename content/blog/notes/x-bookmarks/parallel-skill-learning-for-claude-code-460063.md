## Summary

Hyperbrowser says its **/learn batch** command lets an AI agent learn multiple skills in one command, in parallel. The post shows Claude Code learning a whole stack at once. A setup guide is linked.

## Background

Agent skills are packaged instructions or docs that an agent loads to do a task well. Learning them one by one is slow, so running the step in parallel saves time. This is the vendor's own announcement.

## What I took away

- Skills can be prepared in bulk instead of one at a time.
- Treat the post as a product claim and test it on your own stack.
