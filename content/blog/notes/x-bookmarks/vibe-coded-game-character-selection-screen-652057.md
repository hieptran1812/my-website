## Summary

The author vibe coded a game character selection screen using only AI tools. Nano Banana made the character design and UI, Tencent Hunyuan3D turned images into 3D, and Gemini Pro handled the UI. More details follow in the thread.

## Background

Vibe coding means building by prompting AI. Image-to-3D models turn a picture of a character into a 3D asset. Chaining several AI tools can produce a polished prototype quickly.

## What I took away

- Chaining image, 3D and code models can speed up game prototyping.
- Each tool handled a different step of the pipeline.
- Expect to hand-tune results for production quality.
