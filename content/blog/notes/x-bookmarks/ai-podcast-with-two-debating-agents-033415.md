## Summary

The author says AI podcasts are broken, so they built one where two AI agents debate any topic, interrupt, argue and joke. It remembers the listener's taste and gets better each episode. It is built with Agno and ElevenLabs, and code is linked.

## Background

Agno is an agent framework and ElevenLabs provides synthetic voices. Combining multiple agents with voice and memory creates a conversational format instead of a single narrator.

## What I took away

- Two agents with different roles can make content feel more dynamic.
- Memory of user preferences is a simple way to personalize output.
- The quality claims are the author's own.
