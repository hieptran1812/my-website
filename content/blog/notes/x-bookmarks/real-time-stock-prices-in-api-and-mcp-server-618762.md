## Summary

The post says stock price data is back. The API and MCP server now support real-time and historical stock prices streamed from NYSE, NASDAQ and ARCA.

## Background

MCP (Model Context Protocol) lets AI assistants call external tools and data. Providing prices through MCP lets agents query market data directly.

## What I took away

- Market data can now be piped into AI agents via MCP.
- Check licensing and latency before using in production.
