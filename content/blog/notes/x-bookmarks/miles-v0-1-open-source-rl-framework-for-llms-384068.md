## Summary

RadixArk announced Miles v0.1, an open-source RL framework for LLMs and multimodal models. The team says RL training is easy to start but hard to debug, and Miles is meant to help ensure runs are correct, use hardware efficiently and keep RL running at scale. The work was built over the past nine months.

## Background

Reinforcement learning for LLMs means the model generates outputs, gets rewards, and is updated to make high-reward outputs more likely. It involves both a generation engine and a training engine, which makes bugs such as mismatches between them and wasted GPU time common.

## What I took away

- Correctness checks matter as much as speed in RL training.
- Look for frameworks that help detect silent bugs, not only ones that run fast.
