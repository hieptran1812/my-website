## Summary

The author introduces Anatomy: you describe a machine in one line and Claude builds it. Output includes interactive isometric wireframes you can rotate and inspect, WebGL shaders for fire, water and plasma, and real 3D motion with moving parts. The post is cut off where it explains how to install it.

## Background

WebGL is the browser API for GPU-accelerated 3D graphics, and shaders are small GPU programs that produce visual effects. Tools like this show LLMs generating working graphics code, not just text.

## What I took away

- LLMs can be used to generate interactive visual explainers, not only prose.
