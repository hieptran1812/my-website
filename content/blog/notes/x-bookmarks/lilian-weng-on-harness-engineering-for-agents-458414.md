## Summary

The author recommends a blog post by Lilian Weng on harness engineering, calling it the best post they read all month. It is described as a deep breakdown of harness design patterns, workflow automation, persistent memory through file systems, and how modern agents like Claude Code work.

## Background

Harness engineering is the design of the code and loop around a model: how it calls tools, stores memory, plans and recovers from errors. Using files as memory lets an agent keep notes across long tasks beyond its context window.

## What I took away

- Read it as a map of common harness patterns.
- Files are a simple and reliable form of agent memory.
- Study how existing coding agents work before designing your own.
