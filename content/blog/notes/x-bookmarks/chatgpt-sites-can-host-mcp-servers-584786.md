## Summary

The author says you can now build and deploy MCP servers through ChatGPT, restrict access, or share them publicly. The quoted announcement says ChatGPT Sites can host MCP servers with plugin extensions: a single prompt creates the server, deploys it to Sites, and turns it into a plugin. A further quoted post had asked whether OpenAI-hosted infrastructure would handle backends for plugins.

## Background

MCP (Model Context Protocol) is a standard for connecting AI assistants to tools and data. Hosting MCP servers removes the need to run your own backend.

## What I took away

- Hosted MCP lowers the barrier to building assistant tools.
- Review access controls before sharing tools publicly.
