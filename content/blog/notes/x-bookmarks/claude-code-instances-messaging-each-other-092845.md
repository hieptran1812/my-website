## Summary

The author says they made something so any Claude Code instance can message any other on their machine. They can ask clarifying questions about work, or become friends.

## Background

Letting agents talk to each other lets one session ask another about code it is working on. It is a simple form of multi-agent coordination. The 'become friends' line is a joke.

## What I took away

- Cross-session messaging can reduce duplicated work between agents.
- Think about loops and noise when agents talk freely.
