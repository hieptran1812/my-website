## Summary

The author says they use Claude Code to write reports for their mentor, who finds them hard to understand, so they end up rewriting or explaining verbally. The quoted post lists instructions for making Claude Code speak plain language, such as using standard terminology instead of new phrasings and avoiding metaphors that make readers infer the meaning.

## Background

Coding agents often write in a dense, jargon-heavy style. Adding writing rules to the agent's instructions, for example in a project config file, can change its output style for every task.

## What I took away

- Put writing style rules in your agent's standing instructions.
- Ask for standard terms and no metaphors when the reader is not a specialist.
- Clear reports save time spent explaining them later.
