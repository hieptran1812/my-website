## Summary

Firecrawl recommends a post for anyone doing deep research. The quoted author says their research workflow became 10x better using Claude agent teams and treating the filesystem plus Firecrawl as a web data toolkit: search and scrape for mapping, then real browser environments for pages needing interaction.

## Background

Agent teams are several model instances working in parallel. Saving intermediate data to files lets agents share work without stuffing everything into one context window. The 10x claim is the author's.

## What I took away

- Use the filesystem as shared memory for agents.
- Split research into mapping first, then deeper interactive pages.
