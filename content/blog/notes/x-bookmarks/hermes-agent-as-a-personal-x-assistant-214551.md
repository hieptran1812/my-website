## Summary

The author says Hermes Agent can now act as a personal X assistant and calls the integration extremely useful for people who live on X. He says he will show how to stack Hermes with Grok for a real-time assistant. The details are in the thread.

## Background

Hermes Agent is an agent framework. Integrating it with Grok gives access to live X content. Be careful about permissions when giving an agent access to your accounts.

## What I took away

- Check what account permissions an agent integration requests.
- Promotional urgency (set up ASAP) is not a reason to rush.
- Read the thread for setup steps.
