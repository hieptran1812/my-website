## Summary

The author compares Claude Code's context window usage before and after tool search. They claim a 41% gain. The figure is the author's claim from an attached image.

## Background

Tool search lets an agent load tool definitions only when needed instead of putting all of them in the prompt, which frees context for the actual task.

## What I took away

- Loading tools on demand saves context.
- Check the measurement before trusting the 41% figure.
