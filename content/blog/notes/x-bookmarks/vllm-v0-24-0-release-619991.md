## Summary

@vllm_project announces v0.24.0 with 571 commits from 256 contributors, 77 new. Highlights include MiniMax-M3 support (FP8/MXFP4, AMD tuning), DeepSeek-V4 maturing with FlashInfer sparse index cache, prefill chunk planning on SM120, and Model Runner V2 handling quantized models.

## Background

vLLM is a popular open-source LLM serving engine. Releases add support for new models and kernels, so upgrading can unlock new models and speed.

## What I took away

- Check release notes for new model support.
- Hardware-specific tuning matters.
- Upgrade when you need a new model.
