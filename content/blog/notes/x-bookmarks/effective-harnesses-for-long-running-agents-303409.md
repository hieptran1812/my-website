## Summary

Anthropic says long-running AI agents still struggle when work spans many context windows. They looked to human engineers for inspiration to build a more effective agent harness. The linked post is titled 'Effective harnesses for long-running agents'.

## Background

A context window is how much text a model sees at once. A long task needs several windows, so the agent must hand off progress between them. A harness is the surrounding code that manages that handoff, tools and state.

## What I took away

- Long tasks need explicit handoff between context windows.
- Human engineering practices can inspire agent design.
- Read the post for the concrete method.
