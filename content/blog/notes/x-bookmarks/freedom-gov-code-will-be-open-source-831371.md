## Summary

The author states that every bit of code the government runs for Freedom.gov will be open source, so anyone can verify its security and privacy claims.

## Background

Open source lets outsiders audit claims. Note that publishing code does not prove the deployed system runs exactly that code.

## What I took away

- Open code helps verification but is not proof of what is deployed.
- Look for reproducible builds or audits.
