## Summary

@muratdemirbas calls On System Design by Jim Waldo (2006) a very underrated paper. It distinguishes system design from programming and argues that system design skills are distinct and increasingly rare. The text is cut off.

## Background

System design means shaping how components fit together, handle failure and evolve. This is different from writing code in one module. It is a core skill for senior engineers.

## What I took away

- Design and coding are different skills.
- Read classic papers for lasting ideas.
- Practice making trade-offs.
