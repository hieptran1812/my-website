## Summary

The author claims that Claude Code with **Opus 4.5** helped them build 2 bots for Polymarket in less than 22 minutes.

## Background

Coding agents can scaffold API-based bots quickly. Building a bot is easy compared with making one profitable and safe, since logic bugs can lose money fast.

## What I took away

- Fast building does not mean the bot is good.
- Test bots with tiny amounts and strict limits.
