## Background

MCP (Model Context Protocol) is a standard way to give AI agents access to tools and data, such as browsers or databases. Adding MCP servers extends what Claude Code can do, but each one adds context and risk.

## What I took away

- Add only the MCP servers you really need.
- Check permissions of each server before connecting it.
