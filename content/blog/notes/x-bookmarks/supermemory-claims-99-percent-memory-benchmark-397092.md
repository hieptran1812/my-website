## Summary

The author claims Supermemory reached a '99% SOTA' memory system, so AI agents will 'remember everything', and that it will be open sourced in 11 days. It links to a post by the Supermemory founder.

## Background

Agent memory systems store and retrieve past information so an agent can use it later. A '99%' score depends on which benchmark is used and how it is run, and the post does not say. The release is a promise, so nothing can be checked yet.

## What I took away

- Ask which benchmark and setup sit behind a headline score.
- Wait for the open-source release before judging the system.
- Be careful with hype wording around memory claims.
