## Summary

@techNmak shares a free, open-source learning resource called Before GPU Engineering. It explains GPU architecture and performance engineering from the ground up, as a structured digital notebook with 56 chapters across four phases.

## Background

GPU performance engineering is about making code run fast on GPUs by understanding memory, threads and compute units. Many engineers use GPUs through frameworks without knowing these basics. A structured course helps build that foundation.

## What I took away

- A structured path is useful for learning GPU programming from scratch.
- Learn the memory hierarchy first; most performance issues come from it.
- Bookmark it as a reference while writing kernels.
