## Summary

Tom Doerr shares a neural network library written in C from scratch. The post links to the tensor.h repository on GitHub.

## Background

Writing a tensor and autograd library from scratch in C shows what frameworks like PyTorch do internally. It is a teaching project more than a production tool.

## What I took away

- Reading a from-scratch library is a good way to learn how training works.
- Consider building a tiny version yourself.
