## Per-winner synthesis (#1 to #20 in host order)

### #1 NeuroState: AI-Powered Embedded Systems IDE (Halldean; author Avornyoh Samuel Maxwell)
**Problem and user.** Firmware developers and newcomers to embedded work. The writeup claims engineers spend "60% of their time on boilerplate code and hunting obscure bugs" (writeup, no source).

**What it does.** A visual **finite-state-machine designer** (drag-and-drop nodes, real-time simulation with packet animations). The **"Neo" voice assistant** runs on the **Gemini Live API** and edits the design from speech ("add an interrupt handler for button press"). There is one-click export to **C++, Verilog, Python or Rust**, generated by Gemini 3 Pro with a "32K reasoning budget". A virtual hardware simulator covers GPIO/ADC/UART/PWM. The "Ghost Engineer" static analysis flags dead ends, race conditions and unreachable states. **Image/sketch-to-FSM** conversion and resource estimation round it out.

**Gemini capabilities:** Live API voice, vision (sketch input), long thinking budget for code generation, and structured editing of app state.

**Build, eval, demo.** "Built entirely in Google AI Studio". **No evaluation** of the generated code (no compile or test results). [Video](https://youtu.be/KCaBaoT7CeU), [AI Studio app](https://ai.studio/apps/drive/16lQW--wcmX-q504gliv7dsaNxiG7AY-x?fullscreenApplet=true). Domain: embedded engineering / developer tools.

### #2 Banana Couture: From Prompt to Factory Floor (Drew Williams)
**Problem and user.** Fashion teams that "lose weeks to handoffs between ideation, engineering, and sourcing".

**What it does.** A plain-English brief (e.g. "Retro Knit Polo") produces a high-fidelity concept. The app then exposes **X-Ray** (structure and garment anatomy) and **Tech Pack** views. **FashionGPT**, an autonomous agent, runs the end-to-end pipeline and returns four artifacts:
- Overview: positioning, feasibility, lead time.
- Tech Pack: CAD, measurements, Bill of Materials.
- Costing: COGS plus wholesale/retail guidance.
- Suppliers: "real sourcing suggestions". The writeup does not say whether these are grounded by search.

**Models:**
- **Gemini 3 Pro Preview** for planning, reasoning and multi-step orchestration.
- **Gemini 2.5 Flash Native Audio (Live)** for the "Aura" voice.
- **Nano Banana Pro** for concept and CAD images.
- **Veo** for "Runway" motion previews "(if enabled in your build)".

**Eval, demo.** No evaluation. [Video](https://youtu.be/WtprKEGLH-Y), [AI Studio app](https://ai.studio/apps/drive/15W6RkTNNoZmIIfXLiNxsCwXLZHzX9JCU?fullscreenApplet=true), plus a separate Cloud Run deployment (v3-banana-couture-942375335948.us-west1.run.app). Domain: fashion design and manufacturing.

### #3 SIMUL-AI-TOR: Video-to-Reality Physics Engine (Unoptimized)
**Problem and user.** Students and researchers who can film an experiment but cannot model it. The aim is to move from "passive observation" to "active experimentation".

**What it does.** Upload a clip. Gemini 3 Pro processes the **video directly** to infer kinematic priors (velocity, geometry) and **derives physics parameters** (mass, friction, bounce) specific to that clip. It then builds an interactive 3D sandbox in **Three.js** with **Cannon.js** physics. Users can add or resize objects, control sunlight and gravity, and pause or slow time. An **"AI Research Assistant"** agent reasons over the simulation code and **iteratively rewrites the Cannon.js logic** when physics looks wrong (e.g. momentum conservation). This is a self-correcting code loop.

**Gemini capabilities:** video understanding, code generation (scene graphs, lighting, camera matrices), and reasoning for debugging.

**Eval, demo.** The writeup does not measure how close inferred parameters are to ground truth. [Video](https://youtu.be/MHbY7OpiTKQ), [AI Studio app](https://ai.studio/apps/drive/1UnzbTO4ft6gseOLgGbTlE6nuEo1IyBi8?fullscreenApplet=true), [Cloud Run](https://simul-ai-tor-1007835583290.us-west1.run.app/). Domain: science education / simulation.

### #4 Articulate: The Infinite Canvas That Thinks With You (An Thanh)
**Problem and user.** Visual creators stuck with the "'Gacha' slot machine experience" of text-to-image prompting and the "laziness trap" of copy-pasted prompts.

**What it does.** A multimodal **infinite spatial canvas** where Gemini 3 Pro acts as a "state-managing reasoning engine", or Creative Director. It tackles tool "amnesia" with three mechanisms:
- **Progressive Context Engineering:** a hierarchical memory of user preferences learned in real time.
- **On-the-fly rules:** a tagging system that keeps object generation, visual treatment and "love/hate semantics" consistent.
- **Reasoning-first instructions:** vague requests ("Make it deeper") are interpreted through mood and lighting rather than pixel-level prompts.

The writeup does not name the image-generation model.

**Build, eval, demo.** "Built 100% within Google AI Studio". No evaluation. [Video](https://youtu.be/AA1KhqdeX1k), [AI Studio app](https://ai.studio/apps/drive/1T6M9Ex__TG4e4dT9thI5SkUBBcoNVuJJ?fullscreenApplet=true). The writeup slug is "test-to-see-if-its-working", a leftover title. Domain: creative tools.

### #5 The Lung Listener (Kevin King)
**Problem and user.** Clinicians, especially in telehealth, who cannot auscultate over video and whose crackle/wheeze labels are subjective. The writeup frames the app as a "Glass Box" **research instrument**, not a pneumonia yes/no classifier.

**Data.** Reference cases come from the public **ICBHI 2017 Respiratory Sound Database** (Kaggle mirror). There is no new dataset and no fine-tuning.

**Model and design.** **`gemini-3-pro-preview`**, fed the **raw audio buffer** rather than speech-to-text, so the model "hears" lung-sound texture (musical wheeze vs percussive crackle). Outputs:
- Precise (<2 s) event timestamps, drawn on a Mel-spectrogram (wavesurfer.js) as "purple swimlanes".
- **Overlaid ICBHI human labels** (red/yellow swimlanes). The author uses the overlay to show that ICBHI labels span whole breaths while Gemini pinpoints events inside them.
- A **"DSP Engineer" role**: on a noisy signal, Gemini writes a custom **scipy** high-pass/band-pass filter. The app shows the filter config as JSON and toggles raw vs clean audio.

**Engineering details (writeup).**
- Built "in under 5 days" in AI Studio with React, Tailwind and the Web Audio API.
- Judges get zero-setup testing: a `loadRemoteCase()` fetcher streams .wav files from GitHub raw URLs into the sandboxed AI Studio preview.
- The writeup warns judges about `429 Resource Exhausted` on the shared quota.

**Evaluation.** **None quantitative.** There is no agreement metric against ICBHI labels. The "superior precision" claim is qualitative and visual.

**Roadmap.** Gemini Nano on-device filtering, Littmann Core over Web Bluetooth, and a clinician-feedback loop to build a fine-tuning set.

**Links.** [Video](https://www.youtube.com/watch?v=DeplSlKUGN4), [AI Studio](https://ai.studio/apps/drive/1mwEeTs57pYeME4xJuWNaXOxVR9NWiQpR), [GitHub](https://github.com/kingkw1/lung-listener). Domain: medical audio / pulmonology.

### #6 Voxel Toy Box: Real-Time Multimodal 3D Creation (SAVAŞ HASÇELİK)
**Problem and user.** Casual users and kids for whom 3D modelling is too technical. The app builds on earlier text-to-voxel demos and adds live camera input.

**Three modes:**
- **Mirror Mode:** live video frames go to Gemini vision, which **segments the person and scene and maps colours onto a voxel grid**, giving a real-time voxel "reflection".
- **Catch Mode:** show a real object (cup, toy) to the camera. A **multi-step reasoning chain** follows: Gemini identifies the dominant non-human object, writes a detailed visual description, and that description is **fed back** to generate **JSON coordinate data `{x, y, z, color}`**, which the renderer turns into an inventory asset.
- **Vibe Building:** text prompts ("Build a medieval castle") generate or morph scenes.

**Stack.** React and Three.js on the Gemini 3 Pro API. There is no other model, no dataset and no evaluation. The writeup cites the structured JSON handoff (image, then description, then coordinates) as its proof of "complex, multistep visual logic".

**Links.** The demo video is an [X post](https://x.com/savhascelik/status/1999264510990073896), plus the [AI Studio app](https://ai.studio/apps/drive/1qoKxBYJH9qBpDpaCJ6Hznh4fLC6kjpDt?fullscreenApplet=true). Domain: creative / 3D / education.

### #7 Helix Investigator (Diego Martín Moreno)
**Problem and user.** Biomedical researchers doing literature and database review, which the writeup says takes "weeks" and which the app claims to cut to "minutes" (writeup).

**Agent design.** A tool-using orchestrator built in AI Studio:
- **Pro Agent (Investigator), on Gemini 3 Pro**, calls live APIs (**MyGene.info, PubMed, ClinicalTrials.gov, CIViC**) through function calling for structured data.
- A **"Deep Reasoner" mode** analyses contradictions and outputs research plans with explicit hypotheses.
- **Google Search grounding** supplies the latest web data.
- A **batch processor** takes a CSV of many targets and runs them in parallel.
- **Nano Banana Pro** generates pathway and mechanism illustrations (e.g. p53 pathway, metformin mechanism).

The design deliberately pairs "verifiable data retrieval" from curated databases with generated visuals.

**Eval.** None. No accuracy or hallucination checks are reported.

**Links.** [Video](https://www.youtube.com/watch?v=nQ9R97Wgwx8), [AI Studio app](https://ai.studio/apps/drive/1GdzBCtaPlWtDzB1jMKuYu1zFSPcc9TT_?fullscreenApplet=true), four screenshots. Domain: genomics / bioinformatics research.

### #8 FlameEdit: AI-Powered Video Editor (Muhammad Yousuf Noor)
**Problem and user.** Beginners overwhelmed by video-editing UIs, and experts who want repetitive steps automated.

**What it does.** A full **browser video editor**:
- A lightweight in-browser timeline engine handles trim, split, keyframes, overlays, text, effects, aspect ratio, TTS, and image/video/audio insertion.
- A **Gemini 3 Pro agent** turns natural-language intent into **structured actions that the editor executes directly**. The agent can add and style text, generate images with **Nano Banana**, reposition objects, animate, and adjust clip properties.
- The author pitches it as "antigravity but for video editing".
- The use case shown is step-by-step explainer videos (e.g. solving maths problems). Export goes up to 2K.

**Gemini capabilities:** function-calling-style structured output driving app state, plus image generation.

**Eval.** None. **Links:** [video](https://youtu.be/y_bOyO7qLuQ), [AI Studio app](https://ai.studio/apps/drive/1z_RRg-2CDcCYE8IAKw_SgQdvMkjN7RUE?fullscreenApplet=true). Domain: creative tools / video.

### #9 VOLT: AI Powered Trading for Everyone (Palaniappan Sathappan, Sunny Zalpuri, kuknina)
**Problem and user.** Retail options traders without institutional tools. The writeup cites Bloomberg at "$25,000/year" and pro options tools at "$2,000+ per month" (writeup).

**Agent design: the most tool-heavy of the first 20.** A Gemini 3 Pro assistant with **6 function-calling tools**:
- `get_stock_quote`: price, spread, and IV from the ATM chain.
- `get_fundamentals`
- `get_news_and_sentiment`: bullish/bearish/neutral plus a relevance score.
- `get_whisper_data`: alternative sentiment from Reddit, X, Glassdoor, Google Trends, App Store and LinkedIn, rolled into a composite "Whisper Score".
- `predict_news_impact`: impact %, confidence interval, historical similarity matches, "remaining alpha", and a verdict of "Load the Boat", "Priced In", "Wait" or "Sell Strength".
- `generate_strategy`: contracts, entry/exit, max P/L, probability of profit, Greeks, and a 1 to 10 risk score.

**Memory:** RAG over past analyses using **Gemini Text Embeddings**.

**Other features:**
- A 3D implied-volatility surface on Canvas with **Black-Scholes and Heston** models.
- A multi-leg strategy builder and backtester (equity curve vs buy-and-hold, win rate, max drawdown).
- An "Options Runner" game that replays historical sessions such as the 2022-10-13 CPI reversal.
- Voice input via the Web Speech API.

**Stack.** React 18, TypeScript, Vite, Tailwind, Recharts, a Node/Express backend and SQLite. Market data comes through a provider failover chain: Polygon.io, then Finnhub, Yahoo, Google Finance, and a **"Simulation Mode" for demos**.

**Evaluation.** The only numbers are an illustrative example ("NVDA 4-for-1 split: 87% match to AAPL 2020, +4.2% ±1.8%, alpha remaining 62%"). There is **no backtest result and no prediction-accuracy evaluation**. The writeup also says the model computes Black-Scholes and Greeks "natively", which is **a claim, not a measured result**.

**Links.** [Video](https://youtu.be/c-01KGCGFoo), [AI Studio app](https://ai.studio/apps/drive/12OSK9mHWuAaWfDbFOI3Rht7PYOYz01TM). Writeup about 1,760 words. Domain: retail finance / options.

### #10 FixStream AR: Downloading Expert Intuition into Every Technician (ALAA R)
**Problem and user.** Junior field technicians replacing retiring experts. The writeup's framing statistics are "2.1 million manufacturing jobs" unfilled by 2030 and "$260B+ annual downtime" (writeup, unsourced).

**Pipeline: the most engineered writeup of the first 20 (about 3,100 words).**
1. **Capture (5 to 10 s):** 720p/30 fps video at 750 kbps for 4G, a **client-side FFT** (Web Audio API, FFT size 256, 128 bins) that extracts peak frequency and dB, and **accelerometer** max-g. Sending only numbers cuts the payload (they claim 90% in one place and 99.96% in another, writeup).
2. **Diagnosis:** **Gemini 3 Pro with `thinkingConfig` budget 2,048** plus the **Google Search tool**. Video (base64) and the telemetry block go into one context. A forced JSON schema holds observation, hypotheses, verification, prescription, confidence, safety_warnings and sources. `groundingMetadata` is parsed into clickable citations.
3. **AR guidance:** **Gemini 2.5 Flash** returns `box_2d` boxes on a 0 to 1000 normalised scale, drawn as SVG over the camera feed. **Gemini 2.5 Flash Image** draws "Ghost Mode" semi-transparent wireframes of the state after disassembly. A live chat answers questions about the current frame.
4. **Verification loop:** after the repair, re-record. Gemini 3 Pro compares before and after signatures and returns `repairSuccess` plus deltas. Everything is logged to Supabase as an audit trail.

**Reliability design.** Model tiering with fallback: Pro (180 s timeout), then Flash (60 s), then a canned emergency result. They claim "95% of cases" finish on Pro in under 30 s and a "0% failure rate in field testing" (writeup). The test set is not described.

**Stack.** A React 18/TypeScript/Vite PWA, Supabase and Netlify.

**Evaluation.** **None on real machinery.** The 450 Hz / 0.8 g / 92% figures are illustrative prompt examples, and the source URL in the sample JSON is `example.com`.

**Links.** [Video](https://youtu.be/k3Xk49bgXto), [AI Studio app](https://ai.studio/apps/drive/1weu6pBfuWslZyQy0NGR6xyC87L9fS240?fullscreenApplet=true). Domain: industrial maintenance.

- **Table stakes (all or nearly all of the 20):**

  - Gemini 3 Pro as the core reasoner.
  - A professional or educational user named up front.
